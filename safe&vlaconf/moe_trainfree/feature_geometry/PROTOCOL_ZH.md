# SAFE 式 MoE 特征结构分析

2026-09-06。根据用户对 SAFE Figure 1 的要求，在本轮投影前固定分析方式。
这是已有数据上的解释性探索，不是新的检测器性能实验或盲测。

## 问题

失败是否进入跨任务共享的 MoE 区域、形成多个簇，或表现为表征停止变化？
对照绝对专家使用分布与 v7 的相对动态；不预设一定存在统一失败区。

## 数据与表征

复用第三轮已核验的 A/B 两批缓存，四个 checkpoint 分开分析。
B 的全部 16,000 条轨迹用于固定 query 的原始空间检查。
归一化只使用第三轮第一次划分中 A 的 seen 参考轨迹，不读取其结果标签。

- routing：最后 flow、每层 10 个动作 token 平均概率的平方根，8×32=256 维。
  只做一个全局标量缩放，保留其 Hellinger 距离几何。
- dynamics：各层相对 q1..q4 均值的负对数 mobility，分别做 v7 的 W6 平滑；
  拼接原版 v7 的 W3 acceleration 和 W6 recurrence-loss，共 10 维。
  使用原版 epsilon 与基准，q<7 不读出，归一化采用 A 参考 median/MAD。
  这是保留层结构的 v7 动态表征，不是原版完整的多阈值报警规则。
- 行为只用于解释图：过去最多四个 query 的 EEF 平均位移，不输入 MoE 投影。

没有训练检测头或改变策略。t-SNE/PCA 是仅供分析的无监督投影，确实有数值拟合，
不应称作完全没有拟合的算法；最终标签不参与投影目标或参考归一化。

## 可视化取样

每个任务分别随机取最多 20 条成功、20 条失败，种子 20260906；因此图中类别比例
不是总体失败率。每条轨迹最多均匀取 8 个时刻，避免长失败轨迹单凭长度占满图。
每套件另外加入预先选定的一对同 task/init 成败案例，案例展示全部记录时刻。
按已匹配目标物体 release 时刻相对长度的中位数选失败案例，再取最近 noise seed
的同初态成功分支。该选择发生在投影之前，不按图形或报警表现筛选。

每套件三行图：routing 全时段、routing q>=7、dynamics q>=7。
后两行使用完全相同的 episode/query 点。每行只拟合一次坐标，分别用
SAFE 式结果/进度、任务 ID、最终失败类型、历史 EEF 位移着色。
失败轨迹蓝到红表示 q/(length-1)，不是逐帧失败概率或物理故障标签。

主 t-SNE 固定 perplexity=30、init=PCA、max_iter=1000、seed=20260906。
对配对两种表征另用 seed=20260907/20260908，全部保留；不选最好看的随机种子。
另保存 PCA 投影作线性参照，报告 t-SNE 与原空间 15 邻居的重合率。
联合投影是描述性图，不能当作未见任务部署或泛化测试。

## 原始空间诊断

在 B 的固定绝对 query 7/14/21 各取每条仍有观测轨迹的一个点。
计算原始表征的 20 近邻，候选必须来自同 checkpoint 的其他任务。
同时给出候选总体失败比例和近邻失败比例，分别在失败/成功查询点上按任务宏平均。
差值用于描述跨任务聚集，不是可部署风险分数；邻居标签只用于这个事后诊断。
报告每个 query 的观测覆盖，避免忽略成功轨迹提前退出的影响。

## 案例与核验

直接恢复记录的 sim_state，用原采集环境的 CPU OSMesa 重绘观察画面；不执行新策略。
核验恢复的 qpos 和 EEF 位置，记录图像像素检查。画面是记录状态的重绘，
不是原始 RGB 录像，最后一个记录状态也未必是轨迹终态。
投影路径、v7 freeze 与 EEF 位移用相同 query 索引，标出已匹配 release 事件。
核验动态特征前缀因果性、点与缓存的对应、配对点一致，以及近邻跨任务约束。
