# Round 7: 报警分布与 kNN / v7 / v8 的无训练结合

## 固定方案

本轮由原 kNN 的报警分布提出修改，属于已经探索过 B 的回顾性实验。
不把 B 称为新的盲测集，不根据本轮 B 结果修改候选规则或选择阈值。
不训练策略、分类器或融合权重，不运行新的环境 rollout。

沿用 Round 5 的 12 个划分、A 参考轨迹、A 成功校准轨迹、B 测试轨迹。
每折的 kNN 参考点身份、顺序和数量保持一致；新增维度也取这些参考点。
运行时不输入任务名、成功标签、最终长度或物理状态。
参考库仍使用历史成功标签，因此这里是 train-free，并非完全 label-free。

## 候选规则

1. `knn10`: 原 10 维成功参考 kNN-20，精确欧氏距离。
2. `knn10_persist3`: 连续三次距离的最小值，复现已有持续确认对照。
3. `knn10_delta_q7`: 当前距离减去本轨迹 q7 的距离。
4. `v7_guard`: 复现 SAFE 划分下已实现的 v7 标准化 guard。
5. `v8_guard`: v7 加入前后层 flow 比例倒置、三点曲率两个头。
6. `v82_guard`: 两个 v8 头沿用 v8.2 固定的每 query 0.0015 放宽量。
7. `knn12_v8`: 原 10 维加上两个 v8 平滑量，再计算 kNN-20。
8. `knn_and_v7`: 标准化 kNN 距离与 v7 guard 的逐 query 最小值。
9. `knn_and_v8`: 标准化 kNN 距离与 v8 guard 的逐 query 最小值。
10. `knn_or_v8`: 上述两个标准化分数的逐 query 最大值。

共同确认的主候选事先固定为 `knn_and_v8`，不保证它优于对照。
所有候选完整报告，候选名不等同于结论或正式替换现有版本。

v7 复用原来的三个头、窗口与持久化逻辑。v8 复用前后层比例不做
自身基线、曲率以 q1..q4 为基线、W6 平滑、连续两次确认的机制。
flow_speed 的索引 0/4/8 对应记录的 flow 步 1/5/9。
两个 v8 头的判定从 q6 开始计连续次数，所以独立头最早 q7 确认。
原 v7 freeze 可在 q6 出分，kNN 从 q7 出分。

v7 的分数归一化参数复用相同折的已存 profile。新增维度、融合分数
的中位数/MAD 仅从 A 参考集取得，每条轨迹最多均匀取八个有效点。
融合用 A 参考分数做单位转换，不拟合权重。
每个候选独立按成功校准轨迹峰值、task/init 组峰值取保守 conformal 秩；
主工作点为组校准 alpha=0.05，完整报告原来的 alpha 网格。
最终比较使用严格 score > threshold，与 Round 5 一致。
所以 `v8_guard` / `v82_guard` 是在同一数据划分与校准下的机制适配，
不能冒充原来全局固定阈值版本的原始结果。

## 有效性与审计

v8 原脚本使用 nansum，补齐区可能从全 NaN 变成零并产生有限的前后层
比例。本轮必须在求和、归一化、校准、判定前保留有效 query 掩码；
不能把轨迹结束后的补齐数据作为参考点或报警机会。
读取历史冻结 v7/v8/v8.2/v8.3 报警时，也删除超出真实轨迹的记录，
并单独报告。历史全局 profile 接触过更多 A 任务，只作为历史锚点。

原 kNN、持续 kNN、v7 对照必须复现已经保存的同折分数与报警。
新增 flow 输入先复用现有 v8 缓存，缺失轨迹从原始 router tensor 提取；
记录 episode 身份、长度、有效性、文件哈希以及原始数据重放检查。
新增组合要求前缀因果、补齐不影响输出、reset 清空状态、批量与在线一致。

## 分布和评价

- 完整逐 query 首次报警计数、固定区间计数，并保留未报警类别。
- 累计检出率的分母是全部失败，累计误报率的分母是全部成功。
- 同时给出每个 query 仍在执行且尚未报警的风险集与新增报警率。
- 逐套件、逐任务、逐折报告；汇总时区分折平均和轨迹出现次数合并。
- 物理失败事件前、同 query、事件后的分布，以及未检出的事件。
- 提前量只限制 TP，FP 始终统计全部成功轨迹的任何报警；不能因晚报
  或成功轨迹较短而把误报删除。另列原 v8 的旧口径用于解释差异。
- 共同长度窗口、同任务同 init 的比较，及只使用 query 的时钟对照。
- 对固定 alpha=0.05 的候选报告相对原 kNN 的成对变化；任务 bootstrap
  一起重采样同一任务的全部折记录，避免把重复轨迹当独立样本。

输出新的结果目录，不覆盖原 kNN、v7、v8 已保存的实验。
