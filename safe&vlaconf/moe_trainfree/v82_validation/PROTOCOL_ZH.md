# v8.2 现有语料补充验证

2026-09-08。该协议在本轮实现、运行和查看新结果之前固定。A/B 已用于历史探索，
本轮是回顾性验证，不声称预注册盲测。原始 HUB、既有特征和冻结模型均保持不变。

## 数据与目标

- HUB `cache_new` 的 `right-50x8-20260903` (A) 和 `right-50x8b-20260903` (B)：
  40 任务，各批 16,000 条；按 `(source, episode)` 唯一对齐。
- 已提取的 v7/v8 特征只作为 HUB 路由的派生缓存；逐 run 核对 summaries、长度、
  初态、噪声和既有哈希；抽样从原始 Zarr 再验证。
- 主评价 B 的 16,000 条。A 用于参考与校准；没有新的训练或 rollout。
- q 从零开始，报警 q 时已执行 10*q 个动作。有效记录必须满足 `0 <= q < length`。

## 固定版与补齐修正

重现 v7、v8、v8.2 冻结报警，分别保留既有共同 A/B 的逐位校验。
修正版保留原基线 q1..q4、W6、K2、斜率 -0.0015，仅在原 14,800 条 A 参考的
有效 query 上重新取新增头的 0.995 分位数；原 v7 profile 不变。
另提供仅前后层头、仅曲率头、去时间斜率对照。原版和修正版不会混写。

## 五折初态隔离和校准消融

对 f=0..4：测试为 B 中 init%5=f；成功校准为 A 中 init%5=(f+1)%5；
参考为 A 中其余三个余数组。每折参考 9,600、校准 3,200、测试 3,200；
同一折三部分的 task/init 无交集，全部 B 恰好测试一次。

按已有 temporal_fusion 模式，将各头用参考的 median/MAD 标准化，再保留原
持续确认及锁存 AND/OR。每条参考轨迹每头最多均匀取八个有效时刻，避免长轨迹
主导尺度。v7 的 periodicity scale 也仅用本折参考估计。
这是一组成功预算校准的消融版本，区别于原冻结多阈值规则。

候选：v7、v7+前后层、v7+曲率、v8.2、固定边界 v8、v8.2 新头不平滑、
新头不连续确认、曲率不做开头自基线、前后层单头、曲率单头、末端低运动和时钟。
其他 v7 规则保持原样；新头统一 q6 起有资格判定。

校准单位同时报告成功 episode 峰值和成功 task/init 组峰值；预算固定为
0.005、0.01、0.02、0.05。阈值取 ceil((n+1)*(1-alpha)) 顺序统计量，严格大于
阈值才报警；超出可用秩则阈值为无穷。主校准单位为 task/init，主预算为 0.01。
整个执行期校准一次，不在各检查点重新设阈值。预算相同不意味着 B 的实际 FPR 相同。
共享任务、参考复用和分布变化使这些预算不构成部署时的概率保证。

## 统计指标

- 全程及 q0..q51 累计 TP/FP，分母始终为全部对应成功/失败轨迹。
  已结束轨迹保留结束前的报警。另列当时仍在运行的两类数量。
- 同 task、同 q 且仍在运行的条件 AUROC；另按 task/init/q 比较不同噪声分支。
  没有两类对照的分层记为不可估计，并报告支持数量。
- q7..q13 固定早期区间按 query、task 逐级平均，作为主要条件区分汇总；
  同时保留全部 q，不根据本轮结果挑检查点。
- 95% 区间以 task 为簇、suite 内重采样 2,000 次；冻结已拟合 profile，
  不把 query 或同初态重复分支视为独立样本。不宣称点态区间为同时置信带。
- 每个头的首次触发、并列触发、独有检出和相对 v7 提前量。

## 物理事件与成功对照

用固定 LIBERO/robosuite/MuJoCo 环境，只恢复 B 的全部保存状态，无动作 rollout，
无模型加载。通过现有 PhysicsTask 读取 BDDL 谓词、目标位置、接触和双指抓取。
同一判据用于成功和失败，不调用失败原因分类器给成功轨迹贴失败标签。

- 释放事件：上一检查点观察到抓取，本检查点无抓取。
- 目标未满足时释放：释放时该物体的相关目标谓词尚未全部成立。
- 再抓取及之后满足目标只作事后恢复描述，绝不输入监测器。
- 每 episode 的第一项符合条件的事件用于主要延迟统计；全部物体事件另存。
- 原始/平滑路由统计按物理事件对齐，而非按报警对齐。对每个失败事件，另匹配
  同任务、同 q 仍在运行的成功对照，优先同初态；报告无法匹配的数量。
- 同时比较成功事件和失败事件；逐 offset 报告尚有观测的数量，不补齐终止后分数。

释放可以是正常放置的一部分，不能自动解释成物理故障或不可逆失败；状态分辨率为
10 动作，区间内短时抓取可能遗漏。物理状态恢复不是受控扰动或闭环恢复实验。
