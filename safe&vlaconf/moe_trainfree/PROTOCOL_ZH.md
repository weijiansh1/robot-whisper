# 无训练 MoE 对照 SAFE / VLAConf：第一轮实验

2026-09-06。本轮固定设计在新结果计算前写入；继承的信号设计受过历史结果反馈影响，已有语料不是全新盲测。

## 约束

- 冻结 HiMoE-VLA；不训练分类器、CFN、密度网络或概率校准头。
- 分数和阈值只使用 MoE 缓存、无标签参考统计和当前因果前缀。
- 结果标签只进入独立的评价程序。所有分数、阈值、报警和文件哈希先封存。
- 主工作点固定为无标签参考轨迹总报警预算 3%；1%、5%、10% 全部作为预算曲线报告。该预算不是成功条件下的误报率。
- 主操作基线为既有 v7 的无标签预算版本。其余固定候选全部报告，不根据本轮标签选择主方法或修改公式。

## 数据

参考：`development_main` 14,800 集加 `development_extra` 1,200 集，40 个 LIBERO 任务。
测试：`external_8b` 15,600 集，39 个任务。名称中的 8b 不作为模型大小或分布偏移的证据；此处是缓存标识。
按 `(run_id, task, episode)` 精确连接物理标签，核对 init state、noise seed、query 数和原始成功结果。

这是同一 HiMoE 数据上的方法适配，不是原论文 checkpoint 的逐数值复现。分布扰动、实机和外部专家接管没有对应的新数据，单列为未完成项目。

## 固定方法

正常推理得到的低维候选：后层最后 flow 的 entropy 高/低、低 margin、低 token differentiation、高后层 flow path、后层/前层 flow path 对数比。固定层/flow 消融：前层低 entropy、后层第一 flow 低 entropy、前层低 token differentiation。

时间候选：原 v7 的相对 freeze，沿用其定义与窗口，但只在自身早期参考已经可见后输出。

非参数联合读出：以上六个核心原始通道经参考 median / MAD 归一化后取平均绝对偏差。比较全局参考和逐 query 参考；逐 query 至少 32 个参考样本，否则该位置弃权。MAD 使用 `max(1.4826 * MAD, 1e-6)`，不拟合投影或组合权重。

每个候选固定比较 current、causal mean、prefix max。current 与 prefix max 在相同轨迹峰值阈值下的首次报警等价，因此报警表只保留 current / mean，最大值聚合仍用于排名实验。没有历史的初始 query 只评价当时可用的分数。

对照：只数 query 的时钟、固定随机序列，以及完整 v7 无标签预算 guard。随机控制与真实轨迹共享有效长度掩码。

## 评估设置

1. **cohort_transfer**：全参考 -> 外部噪声队列；初始状态和任务可重叠。
2. **state_heldout**：5 折按 init_state_id mod 5，参考不含对应初始状态，外部每集评分一次。
3. **task_heldout**：按套件内任务排序轮流分成 5 折，参考排除当前任务折，外部每集评分一次。task ID 仅用于分割，不是监测器输入。
4. **suite_heldout**：4 折，每次排除整个测试套件。
5. **reference size**：固定随机种子 20260906，无标签参考子集 N=64/256/1024/4096；全参考是设置 1。用相同候选评价统计参考量的作用，不训练任何模型。

## 逐项对照论文

| 实验 | 本轮执行方式 |
| --- | --- |
| SAFE 失败区分 | 每个测试任务在其最短轨迹长度处统一截断，报告前缀 max 的 pooled / task-macro AUC、AP 与覆盖率；这个取点属于离线评价 |
| SAFE 检测准确率与时间 | 冻结阈值，报告整段 FPR、recall、precision、balanced accuracy、T-det；漏报 T-det=1；失败提前量 0/2/4/8 单列，FP 不按提前量剔除 |
| SAFE 未见任务 | task / suite 留出参考统计；明确继承设计已接触历史任务，不声称全新任务发现 |
| SAFE 失败类型和物理时刻 | 所有失败模式分组；对真实记录的脱手 snapshot 计算 onset 前检出、延迟，注明只有失败轨迹有完整物理事件标注 |
| VLAConf 执行前 / 在线 | q=0/3/7/11/15/19 的当前可用前缀评分，标明存活覆盖率；另列 50% 实际长度事后取点 |
| VLAConf mean / max、NoStep | current / mean / max 以及全局 / 逐 query 无标签参考的固定消融 |
| VLAConf 少量校准数据 | 无标签参考 N 学习曲线；名称为参考规模实验，不等同其带结果标签的概率校准 |
| 概率校准 ECE / Brier / NLL | 无标签秩/偏差不冒充成功概率；本轮不拟合有标签概率映射，因此不作为已复现实验 |
| 分布扰动、实机、选择性专家接管 | 缺少对应新 rollout，不从被动失败检测推导成功率提升 |

时钟在固定 q 上应为 chance；在完整轨迹或完成百分比取点上可能很强。必须并列展示，避免把长度差当作 MoE 信息。

## 核验与报告

- 标签连接必须一对一且全覆盖；原始成功定义不替换为额外延长十个 chunk 后的结果。
- 测试前缀截断不改变之前的分数；warm-up 前不读未来参考；NaN padding 不参与统计。
- 分位阈值按全体参考轨迹计数，平票整体处理；没有可用分数的轨迹保留在覆盖率分母中。
- 对主 3% 报警点给出按 task / init 聚类重采样的区间。所有候选比较是探索性结果，不把最优者的普通区间当作多重选择后的显著性证据。
- 记录 source hashes、拆分、统计参考规模、实际报警率和推理外监测成本。CPU 分数耗时不冒充完整 VLA 推理延迟。
