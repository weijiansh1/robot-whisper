# 第三轮的后续探索：累计分数与参考定义

此设计在第三轮原始结果出来后制定，原始主方法、预测和结论均保留。
所有数据已经参与历史探索；此处不是新盲测，不根据本轮结果继续调参。

原始有符号距离差直接累加可能让早期负值抵消后续异常。SAFE-MLP 实际累加的是
sigmoid 后的非负读数，因此另固定以下三个候选，各比较 current 与 cumsum：

1. `stats_positive`：max(d_success - d_failure, 0)。
2. `stats_ratio`：(d_success + 1e-8)/(d_success + d_failure + 2e-8)。
   这是有界风险比，不称为校准失败概率。
3. `success_only`：只有成功参考参与 median/MAD 和 kNN，彻底移除失败参考。
   原第三轮 `stats_success` 的距离只查成功点，但归一化仍由两类参考共同确定；
   它只能检验减去失败距离这一项的作用，不能称为完整的无失败参考方法。

使用同样的 12 个任务划分、同一每类 4096 点上限、原始成功/失败参考点，
同样的成功轨迹时间带和校准集合。每个方法重新校准自身的阈值，不借用其他方法阈值。
仍不训练任何新增模型。原主方法不会被这些事后候选替换。
复用已提取的全部完整轨迹，输出独立封存文件到 round3_safe/followup。
