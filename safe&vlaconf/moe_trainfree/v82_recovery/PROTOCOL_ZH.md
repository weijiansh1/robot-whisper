# v8.2-R: 可清除路由状态与双重冻结证据

2026-09-08。本协议在查看本轮候选结果之前固定。设计受到已分析 A/B 数据的启发，
属于回顾性方法开发，B 不再是全新盲测。实验不更新策略权重，不执行干预或新 rollout。

## 输入和修改

在线只接收当前 `[8,10,11,32]` 路由概率和 query 计数，不接收任务、初态、物理状态、
成败或剩余时长。沿用 v7/v8 的因果特征、固定开头基线和新增头 W6/K2。

1. 双重冻结证据：原相对冻结分数 AND 当前后四层路由的绝对低 mobility。
   绝对量为 W6 平均的后四层 `-log(mobility)` 中位数。两者分别用参考 median/MAD
   标准化后取 min，避免把相对开头变慢直接等同为当前路由冻结。
2. 近期扰动：加速度与重复结构的持续分数，只在最近四个 query 内各取最大值再取 min。
   原版是整个历史各取最大值；新规则不让很久以前的证据无限参与当前判定。
3. 状态输出：NORMAL / WATCH / ALARM。低阈值来自名义 10% 成功组峰值，
   高阈值来自所选报警预算。连续两个有效 query 不超过低阈值才清除当前状态。
   不将 NaN 当恢复；首次报警和 ever_alarm 永久保留。清除仅指路由信号，不指物理恢复。

所有校准都排除无效补齐 query。冻结参考尺度在执行中不更新。

## 固定候选与对照

按以下顺序固定九种候选，顺序用于最后的复杂度平局裁决：

- `v82_reference`：按同一参考与校准重建的原 v8.2 连续分数族。
- `recent4`：只修改扰动的近期组合。
- `absolute_gate`：只增加绝对低 mobility 的冻结条件。
- `recovery`：同时使用前两项修改。
- `recovery_fixed`：recovery 去掉新增头的时间斜率。
- `recovery_confirm2`：recovery 总分连续两次确认。
- `recovery_confirm3`：recovery 总分连续三次确认。
- `reference_confirm3`：只增加原总分连续三次确认，作为延迟对照。
- `recent4_confirm2`：近期扰动加总分连续两次确认。

原冻结 v8.2、补齐修正版和时钟也报告，但不进入候选选择。新分数与原多阈值布尔规则
不是同一对象，不能直接把两者校准预算视为相同。

## 划分、校准和选择

对 f=0..4：B 的 init%5=f 测试一次；A 中该余数组完全排除。
A 的 (f+1)%5 为校准，(f+4)%5 为开发选择，其余两个余数组为参考。
每折参考 6,400、校准 3,200、开发 3,200、B 测试 3,200。四部分 task/init 互斥。

参考全部轨迹用于分数 median/MAD，每条最多八个时刻；参考 periodicity 的尺度只用参考。
成功校准分别按 episode 和 task/init 最大值聚合全程峰值，名义预算固定为
0.005、0.01、0.02、0.05，主设置沿用 task/init 的 0.01。
顺序统计量为 ceil((n+1)*(1-alpha))，严格大于阈值报警；不可支持的秩取无穷。

选择只用 A 开发结果，逐预算/校准单位分别进行：候选的全程 FP 不得高于同折
v82_reference，TP 不得低于它；在满足约束的候选中，最大化失败的平均及时检出效用：
`exp(-max(first_q-7,0)/12)`，漏检记零。再依次优先 TP 多、FP 少、候选顺序靠前。
原对照始终是合法回退项。该效用只用于开发选择，不作为在线输入，也不是临床或控制成本模型。
阈值和选择产物在输出 B 指标之前写入哈希清单，不依据 B 结果替换候选。

另导出单一在线 profile：A 的 init%5=0,1,2 参考，=3 校准，=4 开发。
该 profile 的选择也只看 A；五折指标评价选型流程，不冒充这个单一 profile 的独立测试结果。

## 评价与停止规则

- 全 B 全程 TP/FP、固定 q7..q51 累计指标，已结束成功仍在分母。
- 同折同预算的 v82_reference、全部九项消融和开发选中版本，分 suite 报告。
- 配对比较漏检/新增检出、成功误报增减、共同检出的提前/延后和中位差。
- 同 task/q 的早期 q7..q13 连续 AUROC；区间按 task 簇在 suite 内重采样 2,000 次。
- WATCH 触发、ALARM 触发和当前状态清除分别报告，清除不扣除 FP。
- 已有成功物理事件及九条释放-报警-再抓取候选仅作诊断，不作 trap 真值或选型标签。
- 与在线逐 query 原始概率回放核对；检查前缀因果性、补齐不变性、状态清除与历史保留。

预先声明的九项候选评价后停止，不因 B 结果增加候选或继续搜索。若没有总体改善，
报告收益与退化，并保留原方法作为回退，不将可清除状态接口本身宣称为检测性能提升。
