# 绝对尺度、共同停滞与序贯累积：固定实验协议

2026-09-09。本轮继续使用已经分析过的 A/B，属于回溯探索。此前新增 AC 报警中
4 个 TP 与 16 个 FP 的初步描述已被查看；没有据此拟合权重或扫描参数。
下列完整模型列表、方向、窗口和预算在本轮模型的 B 指标计算前固定。

## 输入与新假设

沿用当前 HB 路由、AC/ST 自参照和因果平滑，不改变原始编码定义。
当前读取只含路由，不使用时长、进度、物理量、任务 ID 或未来状态。
最终仍为原冻结 v8.2 OR 新增报警；原 v8.2 的 0.0015*q 项原样保留。
不计算仅时长/时钟基线。报警后的信号消退不会撤销历史 FP。

所有原始分量在最近两个平滑位置确认，平滑宽度 3，自参照 q1..4。
记 a 为既有 confirmed acceleration，d 为既有 confirmed recent_decoupling。
新增分量为：

- abs_a：当前 AC 去噪加速度的绝对值取两次较小者，方向为高。
- abs_m：当前 AC 跨查询 mobility 的负值取两次较小者，方向为低 mobility。
- joint_stop=min(max(confirmed(-AC_relative_mobility),0),max(confirmed(-ST_relative_mobility),0))。
- state_trap=min(max(a,0),joint_stop)。

joint_stop 不要求 ST 比 AC 下降更多；它测试二者是否共同减弱。
state_trap 再要求 AC 内部变化增强。名字只描述计算模式，不是物理 trap 的已验证标签。
此次不直接采用全轨迹相关系数，也不将 token 多样性下降默认当作失败条件。

## 校准

继续五折按 `(task, init)` 隔离 A 参考/A 校准/B 测试。
每折参考 9600 A、校准 3200 A、测试 3200 B。
用 A 参考成功轨迹的各分量峰值建立 `e=-log((1+count(peak>=x))/(N+1))`。
joint_stop/state_trap 原始值为零时证据固定为零；缺失保持 NaN。
同一尺度下组合，随后用 A 校准成功轨迹的组合全程峰值建立报警尾部。
参考与阈值校准不共用同一组轨迹；不假设分量独立。
这是成功参考校准，没有分类器、策略、可学习权重或失败标签优化。

## 固定模型

以下 a,d,A,M,J,T 均指六个原始分量对应的参考证据，c=max(a,d)。
首次即时分量通常 q8 就绪。缺失的额外分量不提供证据，不改变分量个数。

| 模型 | 公式 |
|---|---|
| ac_reference | c；与上一轮 ac_recalibrated 必须完全复现 |
| absolute_acc | max(min(a,A),d)；本轮主候选 |
| absolute_both | max(min(a,A),min(d,M)) |
| persistent_ac | max(min_last4(a),min_last4(d))，四个位置必须全部有限 |
| joint_stop_or | max(c,J) |
| absolute_state_trap | max(absolute_acc,T) |
| leaky_ac | L(c) |
| leaky_state_trap | L(absolute_state_trap) |

序贯累积固定为 `L_q=max(0,0.75*L_(q-1)+x_q-log(10))`。
缺失输入重置内部累积为零并输出 NaN；暖机不计入累积。
输入低于参考峰值尾部 10% 所对应的证据时有负增量，支持“可积累、可衰减”的计算异常。
0.75 衰减和四查询持续窗口固定，不扫描。零证据序列保持零，单次扰动会衰减，
不会因为执行时间长而自动增长。该分数不是失败概率，也不宣称任意时域有效的检验保证。
