# 新的 ST/AC 固定组合：2026-09-09

本轮是在已查看 A/B、上一轮硬确认结果之后开展的回溯探索。当前轮的候选公式、
参考/校准划分、预算和评价口径在计算本轮 B 结果前固定；不宣称独立盲测。
无分类器、策略或权重训练，无 B 阈值/方向/窗口选择。

## 1. 保留的规则与输入

- 原冻结 v8.2 的报警始终保留，最终首次报警为旧方法与新增支路的较早者。
  旧方法已有误报也保留；历史报警不因当前异常缓解而取消。
- 使用上一轮已有的 confirmed acceleration、confirmed decoupling、confirmed gap、
  confirmed state_relative_low。所有量仅由当前及过去路由决定。
- gap 为后四层 AC/ST 自参照对数变化差的中位数；正值表示 ST 相对 AC 变弱。
- 新增组合原始量 `state_adjustment=min(max(acceleration,0),max(state_relative_low,0))`。
  两个输入都是已有的连续两次确认分数，所以该量要求它们在相同两个平滑位置同时为正。
  解释为 AC 内部变化增强伴随 ST 跨查询变化减弱，不宣称物理状态停止或不可恢复。
- 沿用 q1..4 自参照、最近三次平滑、相邻两次确认。只对短时错开组合增加最近四次
  查询的最大值窗口；窗口初期使用当前已有的有限值，不使用未来数据。
- 不用总时长、剩余时间、任务进度、物理量或全轨迹相关系数作为分数。
  原 v8.2 的 `0.0015*q` 阈值放宽项原样继承；不计算时长/时钟基线。

## 2. 无训练的两阶段校准

五折仍按 `(task, init_state_id)` 隔离：B init%5=f 测试，A init%5=(f+1)%5
校准，A 另外三个余数参考。每折 9600 A 参考、3200 A 校准、3200 B 测试。
仅使用 A 参考中的成功轨迹峰值，将各分量映射为经验尾部：

```
p_ref(x) = (1 + count(reference_success_peak >= x)) / (N_ref + 1)
evidence = -log(p_ref(x))
```

参考库一律以轨迹为单位。gap<=0 时其 evidence=0；暖机缺失保持 NaN。
随后对整个组合在 A 校准成功轨迹上的全程峰值再次建立尾部库，选阈值。
最终校准分别采用 episode 和 task_init，后者取同 `(task, init)` 成功种子峰值最大值。
无暴露成功轨迹保留为 -inf 峰值。未用同一批 A 校准样本同时拟合前后两阶段。
全程峰值只用于离线参考和阈值校准，在线分数不读取当前轨迹的未来。
所有联合尾部都从成功参考实测，不假设 ST 与 AC 独立，不套用独立检验的分布。

此校准方法不同于此前两个 AC 分量平分 Bonferroni 预算，因此必须加入同校准 AC 对照。

## 3. 固定候选

令 a、d、g、s 分别为 acceleration、decoupling、gap、state_adjustment 的参考 evidence。
令 c=max(a,d)。只有在至少一个 AC 输入有限时组合才就绪；未就绪的额外分量不提供
证据（计算中置零，不改变分量个数）。所有分量正常可用后公式固定不变。

| id | 公式 | 用途 |
|---|---|---|
| ac_recalibrated | c | 同校准 AC 对照 |
| max_or_gap | max(c,g) | AC 或 ST/AC 关系单独足够强 |
| soft_sum_gap | c+g | 软加和，两个信号可共同积累强度；本轮主候选 |
| two_of_three | second_largest(a,d,g) | 任意两个信号支持，允许 AC 两信号自行确认 |
| lagged_agreement | min(max_recent4(c),max_recent4(g)) | 允许证据在最近四次查询错开出现 |
| state_adjustment_or | max(c,s) | 增加 AC 内部变化与 ST 跨查询变化的直接组合 |

不扫描权重、层、窗口、候选方向。软加和各分量权重固定为 1。
每个候选单独评价，不在 B 上取候选的 OR，也不从 B 选赢家作为新默认。
