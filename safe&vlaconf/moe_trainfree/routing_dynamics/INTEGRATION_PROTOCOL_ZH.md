# 无训练路由报警整合协议

固定于运行整合实验之前。A、B 以及 S05 均已被前序分析查看，本实验是回顾性验证，不能称为盲测。

## 输入与固定规则

在线每次只输入 HB 路由概率 `[8,10,11,32]`，不输入任务、结果、最终轨迹长度、任务进度、剩余时间或物理状态。不训练 VLA、分类器、投影或融合权重，不搜索参数。

三条分支：

1. `v82`：复现现有五折 A 参考标准化的 v8.2 连续分数。保留历史 v8.2 的 `0.0015*q` 阈值松弛，明确它仍依赖已观测查询序号。本实验不新增时间分数，也不计算时长基线。
2. `acceleration`：编码器的 `acceleration_log_ratio`，再取连续 2 次查询的最小值；最早 q8 有效。
3. `decoupling`：编码器的 `recent_decoupling`，再取连续 2 次查询的最小值；最早 q11 有效。

编码器参数保持原样：q1..q4 中位数参考，3 次查询平滑，4 次查询动态窗口。这里的 acceleration 是路由在去噪过程中的二阶变化，不是机器人加速度。其余编码字段仅供解释；`routing_recovery` 不作为任务恢复证明，也不否决报警。

## 标定与融合

每条分支在 A 标定集的成功轨迹上取全程峰值。保留没有有效分数的成功轨迹，其峰值为负无穷。分别保存 episode 峰值和同一 `(task, init)` 内成功种子峰值的最大值。

对分支分数 x，以 N 个标定峰值计算：

`p_b(x) = (1 + count(calibration_peak >= x)) / (N + 1)`。

并联 k 条分支时，`p = min(1, k * min(p_b))`，`p <= alpha` 触发。k 固定，不因预热时可用分支减少而改变；全部分支不可用时返回缺失。并联是固定等额误报预算分配，不学习权重。p 是相对成功参考的尾部秩，不能解释为失败概率。

主工作点：`task_init, alpha=0.01`。同步报告 episode 标定及预先固定的 alpha 0.005、0.01、0.02、0.05，不从 B 选择阈值。有限样本分辨率为 `1/(N+1)`；当 `alpha/k` 更小时，该分支无法触发，不能靠插值制造极端分位数。

该构造在对应成功样本单位可交换等条件下具有序贯任意时刻报警的秩标定解释，因为标定使用整条成功轨迹的峰值。多任务混合、相关种子、已查看的数据及不同停止机制限制了形式保证；本报告使用“名义误报预算”，实际误报必须实测。任务初态标定使用各组已有成功种子的最大值，不等同于对所有可能未来种子的保证。

## 固定比较

- `v82_reference`：仅分支 1，占全部 alpha。
- `dynamics_only`：分支 2、3，各占 alpha/2。
- `v82_integrated`：三条分支，各占 alpha/3，为主要整合方法。
- `v82_frozen`：原始冻结阈值的历史工作点。
- `v82_frozen_plus_dynamics`：历史原始报警与 `dynamics_only` 的并集，仅诊断新增证据。它不享有与前三者相同的总误报预算，不能作为公平工作点胜出的依据。

## 数据角色

沿用现有五折：第 f 折，B 的 `init % 5 == f` 为测试，A 的 `init % 5 == (f+1) % 5` 为标定，A 中其余三个余数为参考。每折三个角色的 `(task, init)` 不重叠。每条 B 轨迹只计一次。参考标准化复用原 v8.2 的 A profile，仅保留五条路由统计及 periodicity scale。

在读取 B 分数、汇总 B 指标前，保存所有 profile、阈值及其哈希。已有 A/B 特征已被查看这一事实不因哈希固定而消除。

## 状态与评估

当前状态为 NORMAL/WATCH/ALARM。`p <= 0.1` 进入 WATCH，`p <= alpha` 进入 ALARM；连续 2 次有效 `p > 0.1` 才清除当前状态，缺失不算恢复。首次报警及 ever_alarm 永久保留，一次成功轨迹只要报过警就计一次误报。

报告全程 TP、FP、检出率、误报率，各套件/任务明细，S05，配对新增与丢失检出、增加与消除误报、共同检出轨迹的报警提前量。报告相同任务、查询及可用轨迹上的 AUROC；早期 q7..q13 与全程可比较查询分别统计。AUROC 描述相同观察时刻的区分度，不以最终轨迹时长作为分数。报警占配置动作上限比例仅作离线位置描述，不进入规则。

## 核验

检查秩与相等值、分辨率、预热分支数、连续确认、缺失、状态解除不撤销误报、任意前缀因果性、填充不变性。复现原 v8.2 的缓存分数及所有预算首次报警，核对 16000 条 B、564 失败和 15436 成功。回放原始路由，检查缓存的浮点差异是否影响边界附近的报警。
