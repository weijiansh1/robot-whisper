# 通用路由动力学编码：固定开发范围

2026-09-08。根据已经分析过的 S05 及历史 A/B 数据提出，因此所有现有数据检查均为回顾性检查，不能称作新的盲测。

目标是编码计算状态，不输出失败概率、不建立新报警阈值。保持原始 v7/v8/v8.2 实现不变。不使用时钟、轨迹时长、终止时间、剩余步数、任务身份、初态、动作或物理状态作为在线特征。AS 在当前数据中恒定，不纳入状态编码。

## 固定定义

在线输入只有当前 HB 路由 `[8,10,11,32]`。所有概率按专家维归一化，动作 token 为 1..10。跨查询 mobility 使用最终去噪步的 Hellinger 距离；内部 path 使用 9 次去噪转移 Hellinger 距离之和；内部 acceleration 使用后四层平方根概率的去噪二阶差分范数；token diversity 使用 token 间归一化 JS。

参考窗固定 q1..q4 中位数，当前窗固定最近 3 次查询均值；二者不重叠，首个即时编码在 q7 可用。所有相对量用 `log((current + 1e-6)/(reference + 1e-6))`。这个开头参考是个体尺度，不假定为健康状态。零信号对零参考返回零变化。

数值修正记录：完全相同的浮点数经均值/中位数运算后可能相差几个舍入单位。对绝对值不超过 float64 机器精度 32 倍的对数比归零，防止恒定输入产生虚假的非零占据率。窗口、方向和尺度常数均未调整；原运行单独归档并检查修正前后实测结果差异。

记后四层 mobility 对数变化中位数为 m，内部 acceleration 对数变化为 a：

- `decoupling = min(max(-m,0), max(a,0))`：跨查询变慢与内部二阶变化增强必须同时出现。
- 同时编码 m/a 另外三个符号组合，保留全状态表述，避免只编码某一类失败。
- `path_decoupling` 在每层内合取 mobility 下降与 path 上升，再取后四层中位数；`layer_agreement` 是 8 层中同向参与的比例。
- 保留绝对 mobility、path、acceleration、diversity 和相对量，供分析个体基线造成的偏差。没有新增绝对尺度报警约束。
- 最近 4 次 `decoupling` 的均值、最小值、非零占比，编码近期强度、持续性、占据率；不使用整个历史累计次数或无限锁存。
- 两个相邻 4 次查询窗口间，`decoupling_drop` 编码信号下降；`mobility_rebound` 编码路由重新变化；二者取 min 得到 `routing_recovery`。它仅表示路由信号缓解，不是物理恢复或成功标签。

输出 22 维聚合特征，以及 8 层各 3 个相对量。即时维度 q7 可用，近期维度 q10 可用，缓解维度 q14 可用。不可用值为 NaN，不能当作正常或恢复。在线仅保留开头参考、最近 3 次原始读数及最近 8 次即时特征。

## 检查范围

- 全部 A/B：32,000 条、40 个任务、80 个运行。复用有哈希来源的 mobility、acceleration、token diversity 和 flow speed 缓存；缺失的 flow path 从原始路由补齐。
- 先固定本协议和代码，再查看本轮关联结果。禁止依据 B 的结果追加候选、调整窗口、改变方向或宣称改进已验证。
- 主描述特征固定 `decoupling`；同时报告组成量、path 合取和近期持续量，不挑选赢家。
- 主要统计为相同 task/query 的 AUROC，再按 query、task 等权汇总；方向固定为该字段数值越大。分别查看 q7..q13 和全部可比较 query，并报告样本数和起始可用位置。
- B 上与已有 v8.2 连续分数的比较使用完全相同的 task/query 和观察样本。旧 v8.2 的标准化分数与本次未训练特征不是同一种检测器；不比较未经校准的报警率。
- 主特征另检查相同 task/init/query 对照，及排除启发任务 S05 后的任务汇总。A/B 都是历史数据；不将 A 的方向复现称作独立确认。
- 不使用全程最大值作主指标，不输出时长基线，不执行新 rollout 或策略训练。
- 以原始路由回放、流式/批量一致性、前缀因果性、补齐不变性、专家编号置换不变性、恒定及零变化、短暂/持续/缓解合成输入验证实现。

若跨任务效果弱或不稳定，仍交付可复用编码器并如实报告；不把特征接口等同于已改进的失败检测方法。
