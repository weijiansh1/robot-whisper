# 相对约束与其他固定组合：实验协议

2026-09-09。继续使用已多轮查看的 A/B，所有结果属于回溯探索。
本协议在本轮新模型 B 指标计算前固定，不将反复使用 B 描述为独立盲测。

## 相对约束的定义

既有 AC acceleration 本来就是相对 q1..4 基线的变化。
再次使用同一个相对值约束它没有新增信息。因此本轮用不同计算量的相对增长关系约束。
先沿用当前宽度 3 的因果平滑与 q1..4 冻结参考，记：

- a：AC 去噪加速度的 log(current/reference)。
- p：后四层去噪路径各自 log(current/reference) 的中位数。
- m：后四层跨查询 AC mobility 各自 log(current/reference) 的中位数。
- s：后四层跨查询 ST mobility 各自 log(current/reference) 的中位数。

新的非负分量：K=max(a-p,0)、R=max(p-m,0)、S=max(a-s,0)。
K 检查加速度相对路径的增长，R 检查内部路径相对跨查询移动的增长，S 检查加速度相对 ST 移动的增长。
在 log 空间相减相当于比较相对倍率；这些量仍是路由计算关系，不直接表示物理进展或 trap。
所有新增分量取两次连续位置的较小值，必须有完整窗口。

附加固定方法使用：

- 多层一致性 h：八层中 mobility 相对下降且路径相对上升的比例，取两次较小值，范围 [0,1]。
- 路由缓解 v：既有 routing_recovery，取两次较小值。它需要相邻窗口中的解耦减弱和 mobility 回升；首次通常 q15 就绪。

## 校准与模型

继续五折 `(task, init)` 隔离 A 参考、A 校准和 B 测试。
各原始分量在 A 参考成功轨迹全程峰值上做 `e=-log((1+count(peak>=x))/(N+1))`。
K/R/S/v 原始值为零时证据固定为零，缺失保留 NaN；h 直接作为固定比例，不拟合权重。
记 A,D 为原 acceleration/decoupling 的参考证据，K,R,S,V 为对应新分量证据，C=max(A,D)。

| 模型 | 固定分数 |
|---|---|
| ac_reference | C，必须逐值复现上一轮同校准 AC |
| relative_curvature，主候选 | max(min(A,K),D) |
| relative_path_mobility | max(min(A,R),D) |
| relative_state | max(min(A,S),D) |
| relative_both | max(min(A,K),min(D,R)) |
| relative_soft | max(sqrt(A*K),D) |
| layer_consensus | C*h |
| relative_recovery | max(relative_curvature-V,0)；尚无缓解观测时 V=0 |
| ac_window_mean | 最近四个完整 C 位置的均值，最早 q11 |

所有固定组合再用 A 校准成功轨迹的组合全程峰值校准报警尾部。
主设置 task_init/1%；保留 episode/task_init 与 .005/.01/.02/.05 全部预算。
不扫描参数，不训练分类器、策略或权重，不假设分量独立。
参考校准需要成功标签；这些是无训练的成功参考方法，不是无需任何历史数据的方法。

对照包含旧 AC、同校准 AC、上轮绝对加速度约束、上轮衰减组合和四次持续。
不更改上轮文件和默认入口；最终始终为原冻结 v8.2 OR 新报警。
新增分支不用时长、进度、任务 ID、物理量或未来状态，零输入不累积计时风险。
不运行仅时长/时钟基线；原 v8.2 中已有 0.0015*q 项原样保留。
路由缓解只能影响当前及未来新增分数，不能撤销历史报警或重写历史 FP。

## 评价与验证

所有模型报告完整 B 的 TP/FP，以及与旧 AC、同校准 AC、绝对约束的逐条变化。
报告 50%/60% 配置动作上限前检出，位置仅作事后描述，不进入分数。
AUROC 按同任务、同查询、共同有效观测配对，任务内平均后跨任务平均。
报告 q8..13 与全程可比查询、原始组合分数与最终校准排序，并单列窗口均值的 q11 暖机与暴露差异。
检查盘子旁黑碗任务和成功 episode 174/190；不从计算状态单独断言物理恢复。

重点分析：新相对关系是否留下有用的 AC 信息、约束改变了多少成功峰值和阈值、
K 与旧 a 的相关/裁剪程度、软化或层一致性是否有增量、缓解扣分是否只发生在首次报警之后。
区分原始分数改变、校准阈值改变和查询暴露改变，不选择 B 最优方案作为新默认。

测试相对 log 比值的定义、共同尺度变化抵消、正负方向、软组合、无未来信息、padding、完整窗口、
缓解不撤销报警、在线/批量一致性。独立重建校准库，回放原始路由的任务代表、阈值附近样本、
主候选新报警与关键案例，复算报警指标和抽样 AUROC，核对所有旧结果哈希。
