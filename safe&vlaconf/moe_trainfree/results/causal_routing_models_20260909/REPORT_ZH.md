# 绝对尺度、AC/ST 共同停滞与序贯累积实验

2026-09-09。主候选 `absolute_acc` 在主设置下得到 **482 TP / 112 FP**，此前 AC 组合为
479 / 115。新增 3 条失败全部来自两个空间任务、两个初始状态，且报警较晚。
这是值得继续验证的局部改进，还不是跨任务、全程风险排序的一致提升。

## 数据与约束

- 使用已有 A/B 数据各 16,000 条，共 40 个任务；B 有 564 条失败、15,436 条成功。
- 五折按 `(task, init)` 隔离参考、校准和测试：每折 A 参考 9,600 条、A 校准 3,200 条、B 测试 3,200 条。参考和校准仅使用各自成功轨迹。
- 无分类器、策略训练或可学习权重；只做成功参考分布和报警阈值校准。参数固定，不扫描参数。
- 新分支只读取当前及过去的 HB 路由，不输入总时长、进度、任务 ID、物理量或未来状态。未运行仅时长基线。
- 最终报警为原冻结 v8.2 OR 新分支，保留原 v8.2 的 `0.0015*q` 阈值项。已发生的原报警不会撤销。
- A/B 已被多轮查看，本轮也是回溯探索。公式在本轮 B 指标计算前固定，但不能据此称为独立盲测。
- 主设置为 `task_init / alpha=0.01`；`task_init` 用同任务、同初始状态下成功种子的最大峰值作为一个校准单位，并非逐任务拟合阈值。alpha 属于新增分支，整体 OR 的实际误报率另报。

协议：[CAUSAL_MODELS_PROTOCOL_ZH.md](../../routing_dynamics/CAUSAL_MODELS_PROTOCOL_ZH.md)。

## 组合方式

AC 仍使用去噪加速度相对增强、跨查询移动减弱与内部变化增强的解耦分量。
新增绝对加速度幅度、绝对低 mobility、AC/ST 相对移动同时减弱。
原始分量经过因果平滑和两次确认，再以 A 参考成功轨迹的分量峰值转换为同尺度证据：

`e(x) = -log((1 + count(reference_success_peak >= x)) / (N + 1))`。

以下 `a,d,A,M,J,T` 分别是相对加速度、解耦、绝对加速度、绝对低 mobility、共同停滞、
共同停滞且 AC 相对加速度增强的参考证据；`c=max(a,d)`。
J/T 的原始值为零时证据保持为零，缺失不提供证据。

| 模型 | 固定组合 |
|---|---|
| 同校准 AC 对照 `ac_reference` | `c`，逐值复现上一轮 `ac_recalibrated` |
| 绝对加速度约束 `absolute_acc`，主候选 | `max(min(a,A),d)` |
| 双绝对约束 `absolute_both` | `max(min(a,A),min(d,M))` |
| 四次持续 `persistent_ac` | `max(min_last4(a),min_last4(d))`，完整窗口 |
| 共同停滞 OR `joint_stop_or` | `max(c,J)` |
| 绝对约束 + ST `absolute_state_trap` | `max(absolute_acc,T)` |
| AC 衰减累积 `leaky_ac` | `L(c)` |
| 绝对约束 + ST 衰减累积 `leaky_state_trap` | `L(absolute_state_trap)` |

累积为 `L_q=max(0,0.75*L_(q-1)+x_q-log(10))`。缺失重置、零证据不会自动增长。
所有组合再用独立 A 校准成功轨迹的全程组合峰值确定阈值。
这些分数不是失败概率或对数似然，也不具有已经证明的任意时域错误率保证。

## 主设置结果

以下均为完整 B 的轨迹级最终 OR 报警；TP/FP 分母固定为 564 / 15,436。

| 组合 | TP | FP | 相对旧 AC：新增/丢失 TP | 相对旧 AC：新增/消除 FP |
|---|---:|---:|---:|---:|
| 原冻结 v8.2 | 475 | 99 | - | - |
| 旧 AC 组合 | 479 | 115 | - | - |
| 上轮三信号取二 | 477 | 108 | - | - |
| 同校准 AC 对照 | 476 | 108 | 0 / 3 | 2 / 9 |
| **绝对加速度约束** | **482** | **112** | **3 / 0** | **3 / 6** |
| 双绝对约束 | 479 | 110 | 3 / 3 | 8 / 13 |
| 四次持续 | 480 | 111 | 2 / 1 | 3 / 7 |
| 共同停滞 OR | 476 | 103 | 0 / 3 | 0 / 12 |
| 绝对约束 + ST | 482 | 112 | 3 / 0 | 3 / 6 |
| AC 衰减累积 | 478 | 108 | 1 / 2 | 1 / 8 |
| 绝对约束 + ST 衰减累积 | 480 | 106 | 1 / 0 | 1 / 10 |

主候选召回率 85.46%，实际 FPR 0.726%。相对原 v8.2 多检出 7 条、增加 13 条误报。
相对旧 AC，TP 没有丢失，但共享 TP 中 4 条提前、4 条延迟，不能称为报警时刻也无损。

同校准 AC 对照是隔离新特征作用的重要比较：主候选相对它多 6 TP、净增 4 FP，
其中新增 9 FP、消除 5 FP。因此“482/112 优于旧 AC 的 479/115”不等于绝对约束在所有对照下都同时减少误报。

按 suite 分层、任务为簇的 2,000 次配对 bootstrap：主候选相对旧 AC 的召回变化
为 +0.532 个百分点，95% 区间 [0, 1.497]；FPR 变化 -0.0194 个百分点，区间
[-0.0520, 0.0128]。增益样本少，未作多组合比较校正。

## 为什么绝对约束有效，作用到哪里

这个约束不会抬高任何查询的分数：`absolute_acc <= ac_reference` 在所有有效位置成立。
它压低“相对变化较大，但绝对加速度幅度不强”的异常证据。
五折中分别有 1,013 / 986 / 954 / 993 / 959 条 A 校准成功轨迹的峰值被压低。

| 折 | 同校准 AC 的 1% 阈值 | 绝对约束后的 1% 阈值 |
|---|---:|---:|
| 0 | 7.5273 | 5.5258 |
| 1 | 5.9142 | 5.2412 |
| 2 | 8.4420 | 7.1893 |
| 3 | 8.4442 | 7.7510 |
| 4 | 6.0923 | 5.5533 |

如果固定使用同校准 AC 的旧阈值，绝对约束得到 **476/103**，只消除 5 FP，没有增加 TP。
重新用 A 成功样本校准后才得到 482/112。机制是压低部分成功异常峰值、改变尾部分布，
使具有较强实际幅度的异常可以越过较低的新阈值；不能解释成新分数直接增强了失败证据。

相对旧 AC 新增的 3 条 TP：

| 任务 | episode / init | 首次查询 q | 占配置动作上限 |
|---|---|---:|---:|
| 饼干盒旁黑碗移到盘子 | 11 / 1 | 20 | 90.9% |
| 炉灶上黑碗移到盘子 | 161 / 20 | 15 | 68.2% |
| 炉灶上黑碗移到盘子 | 164 / 20 | 16 | 72.7% |

这三条均由绝对约束后的加速度分支触发，其原 AC 证据没有被裁低。
两个炉灶样本共用一个初始状态，不能把它们当作三个独立场景的普适性证据。
例如炉灶 episode 161 的相对证据 6.3035、绝对证据 9.1367，组合保持 6.3035，
越过新阈值 5.5258，而旧同校准 AC 阈值为 7.5273。
相对旧 AC 消除的 6 条 FP 中，有 3 条已被同校准 AC 对照消除，不能全部归因于绝对约束。

百分比只作事后描述：`10*q / 配置动作上限`，没有使用实际轨迹总长作为模型特征。
旧 AC 在配置上限 50% / 60% 前检出 73 / 158 条；主候选为 74 / 156 条。
因此这轮主要改善完整过程的少量晚期检出，没有解决早期检出。

## ST、持续性与恢复成功

“AC/ST 共同变慢”单独 OR 会提高原始分数，同时令 A 校准阈值更保守。
其主设置 FP 降为 103，但 AUROC 下降；不能把误报下降解释为 ST 已能识别并排除恢复成功。

“绝对约束 + ST”与主候选同为 482/112，但样本不同：补到盘子旁黑碗 episode 363，
也丢掉饼干盒旁黑碗 episode 11；还交换一条 FP。ST 存在局部增量，但当前组合没有净增益。

盘子旁黑碗任务 B 有 24 次失败、376 次成功：

| 组合 | 主设置 TP/FP | episode/1% TP/FP |
|---|---:|---:|
| 原 v8.2 | 18/2 | 18/2 |
| 旧 AC | 18/2 | 19/2 |
| 上轮三信号取二 | 18/2 | 22/3 |
| 绝对加速度约束 | 18/2 | 20/2 |
| 双绝对约束 | 18/2 | 20/3 |
| 绝对约束 + ST | 19/2 | 21/3 |
| 四次持续 | 18/2 | 19/2 |
| 绝对约束 + ST 衰减累积 | 18/2 | 19/2 |

ST 在主设置补到 episode 363 的 q21，已达配置上限 95.5%。成功 episode 174 的
历史误报仍保留；加 ST 后从 q17 提前到 q15。成功 episode 190 在主设置仍不报，
但在较宽松的 episode/1% 下，双绝对约束和绝对约束 + ST 都在 q18 误报。
这些结果仍与“成功过程中也能出现相似内部异常，之后继续完成任务”相容。
本实验不重新判定这些样本是否具有物理 trap，也不把路由信号消退等同于物理恢复。

四次持续最早 q11 就绪，普通分支 q8 就绪。B 中有可用评分的成功轨迹从 14,292 条
降至 10,571 条，而失败仍为 564 条。持续模型的统计必须在匹配查询上比较，不能把
未暴露的短成功轨迹增多当成动力学区分能力增强。

衰减累积的主设置可减少部分误报，但把 AC 的 89.8% 成功查询、45.7% 失败查询压为零；
绝对约束 + ST 累积对应 91.7% / 49.0%。大量并列零分损失了连续风险排序信息。
它可以作为高阈值报警候选，当前结果不支持将其视为更好的全程风险分数。

## AUROC

先在同任务、同查询、共同有限观测的成功/失败之间计算，再任务内平均查询、跨任务平均。
不对已经结束的成功轨迹补分，不把整段轨迹时长转为风险。
“全程”指全部可比查询，不能解读为利用完整轨迹峰值进行二分类的 AUROC。

| 模型 | 原始组合分数 q8..13 | 原始组合分数全程 | 最终校准排序 q8..13 | 最终校准排序全程 |
|---|---:|---:|---:|---:|
| 旧 AC 排序基线 | 0.7209 | 0.7048 | - | - |
| 同校准 AC | 0.7177 | 0.7002 | 0.7264 | 0.7054 |

| 双绝对约束 | 0.7435 | 0.7064 | 0.7648 | 0.7216 |
| 共同停滞 OR | 0.6532 | 0.6633 | 0.6579 | 0.6692 |
| 绝对约束 + ST | 0.7356 | 0.6925 | 0.7591 | 0.7111 |
| AC 衰减累积 | 0.5641 | 0.5839 | 0.5899 | 0.6182 |
| 绝对约束 + ST 衰减累积 | 0.5670 | 0.5723 | 0.5879 | 0.6013 |

上表为 36 个有可比正负样本的任务。不同折的单调校准映射及并列分数处理会改变跨折排序，
因此原始分数与最终校准排序两种结果都保留，不能挑选其中较好的数字。

持续模型仅 32 个任务、最早 q11 可比：原始分数 q11..13 / 全程为 0.6958 / 0.6663，
同样本同查询 AC 对照为 0.6976 / 0.6742。不能直接与上表 36 任务、从 q8 起的数字作差。

主候选相对同校准 AC 的原始 AUROC 变化：早段 +0.0145，95% 任务 bootstrap 区间
[-0.0009, 0.0314]；全程 -0.0021，区间 [-0.0192, 0.0141]。
双绝对约束的早段变化 +0.0259，区间 [0.0041, 0.0474]，全程变化 +0.0061，区间
[-0.0225, 0.0330]。排除盘子旁黑碗任务仍有相似早段趋势，但全程证据不足；
所有这些区间都是回溯、多组合探索下的描述性区间。

## 验证与复现

- 31 项单元检查通过，包含前缀因果性、padding、完整持续窗口、零证据不增长、缺失重置、在线/批量一致性及报警保留。
- 五折 110 个参考和最终峰值库独立重建，分组隔离检查通过。
- 回放 203 条原始轨迹、6,841 次查询，覆盖 112 条阈值附近轨迹及主候选新增报警。12,992 次首次报警比较全部一致。
- 浮点分数并非逐值完全相同：最大原始分量差 4.16e-5，最大模型分数差 0.00717；这些回放样本的报警决策没有变化。
- 独立复算 3,645 行报警指标、8,280 行配对变化和 383 个 AUROC；1,024,000 次原报警保留检查、505,752 次分数方向检查通过。
