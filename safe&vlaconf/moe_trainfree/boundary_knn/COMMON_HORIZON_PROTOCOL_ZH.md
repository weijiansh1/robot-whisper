# LIBERO-10：成功终止之前的共同窗口评价

本轮只评价现有 LIBERO-10 / `libero_long` 的 8,000 条轨迹，复用 Round 11 封存的逐 query 分数、四轮完整任务留出和历史成功校准数据。不更新策略、特征、参考成员或聚类，不新增 rollout。

## 时间和窗口

- q 从 0 起计数。q 时刻已经执行 10*q 个动作，当前预测的 chunk 尚未执行。
- 只使用实际记录的 query。q0-q6 没有有效动态分数，仍保持缺失。
- `full`：复现原完整轨迹结果，作为锚点。
- `task_common`：每个任务取其全部 A+B 轨迹的最短实际动作长度 T。该任务的所有轨迹一律只评分满足 10*q < T 的 query。终止时刻本身被严格排除。
- `fixed_q07` 至全套件最早终止之前的最后 query：所有 8,000 条轨迹使用同一个 q 上限，保留全部成功、失败样本，不按是否仍在执行筛选人群。
- 本批最早成功终止为第 140 个动作，因此全体共同的最后推理点为 q13 / 已执行 130 个动作；固定检查点完整列出 q7-q13，不按效果挑选。
- 检查每个任务的最短终止确实对应成功，且所有窗口的最后 query 对全部轨迹有效。不能把不等长轨迹补成新的观测。

这里只控制成功终止造成的观察时长差异。某个失败轨迹可能早已发生物理错误，不能把“成功终止之前”直接解释成“物理失败之前”。

最短长度是事后用于评价的统计量，不作为新任务在线监测器可预知的截止时间。参考建库仍可使用历史轨迹的完整信息，这与截断待评价轨迹不同。

## 分数和阈值

固定四个已有方法：kNN-20、C32 中心距离、C4 中心距离、C4 最近簇半径归一化。C4 仍是此前历史数据上的探索候选。

对每个窗口报告两种阈值设置：

1. `frozen_full`：保留 Round 11 的完整历史轨迹校准阈值，只提前停止读取测试轨迹。回答原先 82 条误报和 405 条检出中有多少已经在这个窗口发生。
2. `prefix_calibration`：将本轮独立历史校准轨迹也限制在相同 q 上限内，再按成功轨迹峰值、task/init 组峰值和名义 alpha=5% 的有限样本分位数重算阈值。每个测试任务有自己的共同上限时，使用该上限截断其所在折的校准数据；校准轨迹若更早结束，只用其真实可用前缀。全体 q13 的校准和测试轨迹均尚未终止。

校准只使用原先分配的 A 校准轨迹及其历史结果标签，不使用本轮测试轨迹的分数或结果来选择阈值。窗口长度来自事后数据结构，因此整项实验仍是回顾性诊断，不是新的盲测或部署性能保证。

## 指标与混淆检查

- TP、FP、FN、TN、召回率、成功误报率、报警精确率、首次报警 query；完整分母为 541 失败和 7,459 成功。
- 窗口内峰值以及窗口末端值两种 ROC-AUC，以覆盖 SAFE 正文/附录取分数表述的差异。
- 原分数 AUC、除以各折/窗口校准阈值后的 AUC 均保留。归一化峰值 AUC 与上一轮报告口径衔接。
- 同时报告整体、task、fold、A/B；任务内平均 AUC 用于检查不同任务的时间和分数尺度混淆。
- 单独计算时间基线：完整窗口使用最终动作长度，截断窗口使用已执行的共同动作数。全套件固定 q 的时间基线 AUC 应为 0.5，每个任务内部的共同窗口时间基线也应为 0.5。
- 不把单个报警点的 balanced accuracy 当作 AUROC，不把窗口内最终失败检出解释为已可救回。

## 核验与输出

读取前核对封存输入 SHA-256；逐条复现四个方法原报警、峰值和阈值。检查任务隔离、时间严格早于终止、所有 8,000 条轨迹唯一覆盖、没有丢弃不利样本、截断后原阈值报警只能减少、重校准仅使用成功校准组。

新输出写入 `results/round12_common_horizon/`，拒绝覆盖已有目录：总体/分组指标、每任务截止时间、全部窗口逐轨迹 NPZ、原 82 条成功误报的身份和截断后状态、逐 query 早期曲线、图表与核验记录。Round 11 源码及封存产物保持原样。
