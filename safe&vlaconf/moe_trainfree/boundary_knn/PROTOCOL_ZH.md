# 外围假设与 kNN：运行前固定方案

2026-09-06。用户要求尝试外围分数及 kNN。本轮是已经探索过的缓存上的后续实验。

## 数据和划分

复用 round3_safe 的 32,000 条轨迹和已核验特征，四个 checkpoint 分开。
沿用种子 20260907/20260908/20260909 的 7 seen / 3 unseen 任务划分：
每折 A 中 1,680 条作参考、560 条作校准，B 中 1,760 条作测试。
参考、校准、seen 测试的 task/init 不重叠，A/B 的噪声种子分开。
评分过程只读 A 的历史成败标签，B 的标签在所有分数和阈值保存后才由评估器读取。
这些数据已经被观察过，本轮不是新的盲测。

## 表征和参考库

采用第四轮相同的 10 维 v7 动态及 256 维平方根路由分布。
每折重新用自身 A 参考集确定周期性尺度与 median/MAD，不能沿用其他折的统计。
路由仅用全局标量缩放，保留 Hellinger 几何；所有新分数 q7 前等待。
每条参考轨迹最多均匀取 8 个 q>=7 的有限点，每个库最多 4,096 点，固定按本折种子抽样。
成功库只含 A 参考中的成功轨迹；混合库按参考样本的自然构成取样，并记录成败标签。
归一化使用未按成败过滤的 A 参考，所以“到成功库的距离”不等同于全流程不读失败数据。
所有近邻是精确欧氏近邻，不训练网络；参考筛选和成功校准会使用历史标签。

## 固定候选

主方法为 `dyn_success_knn_k20`，其他候选全部保留，不根据 B 的结果选参。

- `dyn_radius`：归一化动态到参考中心的欧氏半径。
- `dyn_radius_outward`：当前半径减去自身 q7 半径。
- `dyn_success_knn_k1/k5/k20`：到成功参考库最近 k 个点的平均距离。
- `dyn_success_knn_k20_persist3`：最近连续 3 个有效 query 的 k20 分数最小值，q9 前等待。
- `dyn_vote_knn_k20`：混合参考库 20 近邻中失败标签的比例；标签表示最终结果，不是逐帧故障。
- `dyn_pca2_success_knn_k20`：PCA 仅拟合 A 混合参考库，冻结二维投影后检索成功近邻。
- `route_success_knn_k20`：相同参考 episode/query 的 256 维路由距离。
- `eef_motion_low` 和 `clock_q7`：相同等待期的行为和时钟对照。

不对测试 t-SNE 联合坐标直接做部署评分。二维 PCA 保留标准线性变换用于新样本。
不累加非负距离，不拟合融合权重。本轮比较原 v7 已保存的结果，不修改其规则。

## 校准和评估

对独立 A 成功校准轨迹的全程分数峰值做有限样本顺序统计量校准。
同时报告 episode 和 task/init 组峰值两种方式，alpha 为 1/3/5/10/15/20%，主工作点为组校准 5%。
使用常数阈值，不估计参考分数的时间带，因此无需让参考轨迹对自己的邻居距离参与分数校准。
测试时只要当前分数严格大于阈值就报警并锁存；短轨迹的等待期不从误报分母剔除。
未见任务存在分布变化，标称 alpha 不保证迁移后的真实 FPR。

沿用第三轮的全程与同任务统一观察长度 AUC、同初态 AUC、seen/unseen 分组，
另保留 q7/q14/q21 的固定时刻前缀评价。观察长度仅用于离线评估，不输入检测器。
同时报告 recall/FPR、检出时间和相对目标匹配 release 的时序；释放事件不等于不可逆失败起点。
重复划分不能当作独立新增轨迹。比较时读取相同测试行的旧预测，分别标注旧 CP 与原 v7 预算规则。

## 核验和产物

保存参考点身份、PCA 参数、全部预测、阈值和哈希；直接距离排序复算 kNN 与投票，
核验划分和校准秩，并从原始路由逐 query 重放在线 monitor。
执行 CPU 分析，不加载策略模型、不进行新训练或 rollout。
