# 块内路由网格的谱结构：一个形状，不是一个信号

> 2026-09-03。提议来自 2026-09-02："就看层和激活，一个 chunk 的一次去噪步内组织成一个张量，
> 算主成分，按 token×去噪做成 10×10 矩阵，做特征值判断。"
> 脚本 `spectral_grid.py` → `spectral_grid_results.csv`；特征缓存 `.layer_axis_cache/spectral_feats_{A,B}.npy`。

## 做法

每个控制步：取 8 层 × 10 去噪 × 10 动作 token × 32 专家，重排为 **100 格 (去噪×token) × 256 维 (层×专家)**，
减去块均值。八个纯瞬时特征（不看历史）：

| 特征 | 含义 |
|---|---|
| `evr1` | 100 格 PCA 的 PC1 方差占比 |
| `pr_cells` | 100 格谱的参与比（有效维数，上限 99）|
| `s1frac` / `pr_s` | PC1 得分排成 10×10（去噪×token）的 σ₁ 占比 / 参与比 |
| `tok_lam1` / `tok_pr` | token-Gram（10×10 余弦，去噪上平均）的 λ₁ 占比 / 参与比 |
| `den_lam1` / `den_pr` | 去噪-Gram 的 λ₁ 占比 / 参与比 |

协议照 `top4mass.py`：current / win8 / d_win8 三种读法，组内配对 AUC，maxT 家族置换，对换手率基线秩残差，语料 A（rolling-star）+ B（HUB 16×32）。

## 结果一：块内结构是什么

| | A | B |
|---|---:|---:|
| `pr_cells` 中位 | 6.50 | 6.66 |
| `evr1` 中位 | 0.316 | 0.307 |
| 参照：每格专家打乱 | — | 62 |
| 参照：iid 高斯同方差 | — | 71 |

**比噪声低 10 倍**。方差分解：**token 主效应 72%**、去噪 12%、交互 15%。
即"十个动作位置各有一个路由签名，相邻位置部分重叠；去噪轴几乎不贡献"。

和跨 chunk 的旧结论拼在一起：**每个动作位置有自己的地址（块内 72%），换 chunk 时所有地址一起挪（跨 chunk 相关 0.83–0.97）。**

## 结果二：当检测器——有信号，最不冗余，仍未过双语料残差

原始判出率（win8, t=30）：`evr1` **A 0.719 / B 0.732**（基线 0.799 / 0.751）。
和基线的 Spearman ρ ≈ **0.65**（低于"同一测量"的 0.8 线）。

| | 原始 p<0.05 | 残差后 p<0.05 | 最强残差存活 |
|---|---:|---:|---|
| B | 16/96 | 6/96 | `evr1\|win8` t=30：0.646, p=0.001 |
| A | 17/96 | **0/96** | — |
| 交集 | | | **空** |

和 646 种切法同一结局。差别是这一个走得最远：两批原始信号相当、与基线只中等相关、B 上残差显著。
项目关掉的瞬时标量（熵、top-4 质量、参与率）全在 0.46–0.55；**二维网格的谱确实比标量多知道一些**，但不够。

## 结果三：卡住时它往哪变（两批 14/16 组同号）

t∈[28,35) 窗口均值，组内（失败−成功）：

| 量 | B：成功 → 失败 | A：成功 → 失败 | 同号组 |
|---|---|---|---|
| `evr1` | 0.321 → **0.269** | 0.353 → **0.288** | 11/13, 2/3 |
| `pr_cells` | 6.39 → **7.44** | 5.77 → **7.07** | 11/13, 3/3 |
| `tok_pr` | 5.75 → **6.46** | 5.47 → **6.20** | 10/13, 3/3 |
| `den_pr` | 1.73 → 1.74 | 1.73 → 1.76 | 不变 |
| 方差分解 | 72/12/16 → 71/13/16 | 72/12/15 → 71/13/16 | 不变 |

**卡住时位置结构没有塌（72% 保留），但 10 个位置的共享方向变弱、各自散开。去噪轴不受影响。**

解释：换手率说"路由跨 chunk 变得少"；块内结构说"一个 chunk 内 10 步动作视界的共同方向变弱"。
卡住的模型反复吐出几乎同一个 chunk，而 chunk 内部位置间的协调在下降。
**这是第一次在单次前向传播内部描述 trap**——此前所有描述都要历史。

## 能拿来做什么（按确定性）

1. **动作 token 干预的合法形状。** Slide 8 缺的"L2 分布合法"判据：动作 token 路由状态须满足 PR≈6.5、token 主效应≈72%、去噪≈12%。
   把 10 个位置钉成同一路由 = 72% 方差 off-manifold。`build_switch_pin.py` 只钉过 state token（流形平凡）；动作 token 的流形现在能量了。
2. **一个有假设的干预靶子。** trap 签名 = 共享方向变弱 → 把 chunk 的动作路由投回自身 PC1（恢复相干）是 on-manifold、对症、可在分叉框架里测的 pin。
   对照：同幅度随机方向。这是干预线上第一个不靠重抽噪声的候选。
3. **跨模型指纹。** PR 6.5、72/12/15 无标签、架构级；第二个 checkpoint 只需采路由。跨模型现在零数据，这是最便宜的一格。
4. **压缩。** 每 chunk 动作路由 ≈ 7 个数，跨 chunk 分析可在此无损进行。

## 做不了什么

**检测。** 块内结构再丰富也是所有 rollout 共有的位置标签；跨 rollout 只有 ≈2 个自由度（`moe_info.py`，t=30 原始张量组内中心化，PR 1.81/2.25）是硬约束。
`evr1` 原始 0.72 在 A 上残差归零，已证。
