# VLAConf 思路的 MoE 概率校准实验

## 主要发现

局部成功支持度加两参数校准的总体 AUROC 为 0.7435，Brier 为 0.07740；同点比较的原无预算监督 MoE 模型为 0.9092 / 0.05833。这版固定分数有总体预测价值，但损失明显更高。

在同任务、同 q、同物理阶段的比较中，主方法 AUROC 为 0.4955 [0.3968, 0.5952]，未发现稳定的局部区分能力。这是匹配覆盖子集上的结果，不代表所有状态都没有信息，也不能将总体与匹配结果的差额作因果分解。

未见任务的局部方法 AUROC 为 0.7359，Brier 为 0.09633。相对常数先验的 Brier 差为 -0.00227 [-0.01465, +0.00935]，区间跨过零；跨任务的绝对概率尚无稳定优于先验的证据。

历史最大值在本次总体排名更好：共享模型 AUROC 0.7897，未见任务为 0.8336。代价是概率不能反映恢复后的回升，而且其未见任务 Brier 仍高于原监督模型。没有据此替换预先指定的局部主方法。

## 本次实现

本实验将成功支持度分数与终局概率校准分开。VLAConf 使用成功示范训练 CFN；这里固定既有 18 维 MoE 局部特征，用成功训练轨迹的近邻距离替代 CFN。这是方法借鉴，不是原论文网络、输入或成绩的复现。

成功训练前缀用于拟合逐坐标均值/标准差并建立参考库；k 固定为 20。当前风险分数为标准化空间中最近 20 个成功前缀的平均欧氏距离，再取 log1p。不训练新的高容量预测模型或神经网络。参考库选择仍使用成功标签，不能称为完全不依赖标签。

主方法取最近 4 个可用分数的均值，拟合 p= sigmoid(-alpha*u+beta)，alpha>=0。独立校准集提供成败标签，用来拟合这两个参数。每种聚合单独校准，所有任务/suite 共用映射。另保留当前分数、历史均值、历史最大值，以及既有冻结分数的固定对照。

## 数据与目标

复用完整 32,000 集、508,023 个原始 query 的已验证缓存；q>=7 的 284,023 个前缀符合本方法输入要求。前 7 个 query 不输出概率，不按最终长度或执行百分比选点。

| 集合 | 轨迹数 | 前缀数 | 成功前缀数 |
|---|---:|---:|---:|
| calibration | 3,164 | 28,049 | 25,643 |
| test_new_noise_seen_init | 12,679 | 114,120 | 99,488 |
| test_unseen_init | 6,368 | 56,437 | 50,218 |
| train | 9,515 | 85,417 | 73,854 |

共享成功参考库包含 73,854 个前缀，来自 9,152 条训练成功轨迹。主测试初态与参考库/校准集隔离；五折未见任务同时从参考库、标准化和校准中排除测试任务。

在线不传步数、预算、任务/suite 或物理状态。主方法最多涉及最近 11 个 router query；历史聚合仍可能隐含累计时间。MoE 本身也可能编码任务/阶段，不能声称与时间统计独立。

预测目标仍是原始截止条件下的终局成功，不是无限时域或任意指定预算的成功概率，也不是未来 5 个 chunk 的物理进展或真实 trap 脱困概率。

## 校准与恢复动态

单调 sigmoid 只改变分数刻度，不能修复错误的排序。metrics.csv 同时保存校准前原始分数的 AUROC；所有已声明方法均报告，没有按测试指标挑选聚合方式。不同未见任务折使用不同映射，因此跨折合并后的排序不必保持不变。

| 共享校准方法 | alpha | beta |
|---|---:|---:|
| support_current | 7.549856 | 8.334601 |
| support_window4 | 8.691589 | 9.161575 |
| support_prefix_mean | 9.706744 | 9.780013 |
| support_prefix_max | 7.730954 | 9.444111 |
| freeze | 2.747177 | 2.454144 |

共有 0 / 30 个拟合的斜率为零。零斜率意味着给定分数方向下最优映射退化为常数。

历史最大风险分数不能下降，所以对应成功概率不能回升。局部均值允许回升，但回升本身不证明机器人已经物理脱困。以下仅统计有下一观测点的相邻概率变化，没有把成功终止后的未观测点补成 1。

| 聚合 | 主测试相邻点 | 概率回升次数 | 回升比例 |
|---|---:|---:|---:|
| support_current | 50,069 | 24,034 | 48.00% |
| support_window4 | 50,069 | 25,056 | 50.04% |
| support_prefix_mean | 50,069 | 23,280 | 46.50% |
| support_prefix_max | 50,069 | 0 | 0.00% |

首次 half-k4 报警后的逐点变化另存 first_alarm_probabilities.csv；这些仍是既有报警的描述，不是独立确认的真实 trap 样本。

## 证据边界

物理阶段匹配覆盖 25,472 / 56,437 个主测试点。阶段仅包含目标谓词、抓取、抬升和接近的离散摘要，不代表完整物理状态。匹配也改变了可比较样本及正负样本对的权重。原物理恢复审计发现 290 个采集时仍活动的检查点恢复后已满足全部目标；这里仍以采集器终局标签为准，所有点沿用同一输入风险集，不按未来物理事件筛选。

成功支持度不等于成功后验。成功库中常见的模式也可能出现在失败轨迹；相似邻居可能来自同一轨迹，且查询密度、尺度及特征冗余均会影响距离。两参数概率校准不能补回固定分数丢失的信息。

这是已探索数据上的追加实验。未新增任务、策略或同检查点分支续跑；不能将每个前缀的一次 0/1 结果解释成该物理检查点的精确成功概率。

## 在线一致性与复现

原始路由抽查覆盖 80 个源 run、1,256 个 query；核对 696 个就绪点的四种聚合，共 2,784 个概率。最大概率误差 0，最大分数误差 0。训练集抽样只检查批量/流式数学一致性，不报告自身近邻库上的训练成绩。

本机四线程 CPU 单点同步接口耗时中位数 1.43 ms，95 分位 1.50 ms，不包含 VLA 推理。近邻参考库有存储与检索成本，与小型神经置信度头的部署开销不同。

```bash
env OMP_NUM_THREADS=4 OPENBLAS_NUM_THREADS=4 python -m probability.run_scalar_confidence --threads 4
python -m probability.run_scalar_confidence --render-only
```

在线 bundle 为 models/shared.joblib；每集新建 MoEScalarMonitor，调用 update(hb_router_probs)。当前已采样 chunk 必须保留，输出不能直接外推到改变策略、延长预算或不同动作采样配置。

方法协议：[VLACONF_PROTOCOL.md](../VLACONF_PROTOCOL.md)。论文原方法：[VLAConf v2](https://arxiv.org/html/2605.29605v2)。
