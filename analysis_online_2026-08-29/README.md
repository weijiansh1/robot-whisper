# MoE 路由的在线失败检测(2026-08-29)

**一句话**:MoE 路由的跨 chunk 变化率可以在 rollout 跑到约 60% 时在线判定它会不会失败 ——
**等机会窗口内 6–8% 误报换 74%–76% 检出**,只用 t 时刻之前的路由,不用总长度、不用外部参照。
**没有提前量**:第 28 步之前判对率等于基线。

## 语料与协议

**语料 B** — `VLA_MUI_HUB/cache/HiMoE-VLA/libero_long/KITCHEN_SCENE8_put_both_moka_pots_on_the_stove/right-16x32`

- 512 条 = 16 初态 × 32 种子,**296 成功 / 216 失败**
- 长度:成功 35–52,**失败 52–52(全部跑满 horizon)**
- 分组:`init_state_id`(16 个),全部评测留一初态
- 失败分类(冻结物理判据移植,见 `data/labels_B_derived.csv`):
  **停滞 128 / loop 41 / other 47**

**评分** — 每个控制步一个标量:相邻两 chunk 的 router 概率向量之间的距离,
在 HB 层 12–15、去噪第 9 轮、逐 (层, token) 位点计算后取平均。

- `st_deep` = 后缀 token 0(4 个位点)
- `ac_deep` = 后缀 token 1–10(40 个位点)

t 时刻的运行分数 = 最近 **W** 个距离的均值。**不用 t 之后的任何东西,不用总长度。**

**阈值** — 留一初态。对测试初态 g,取其他 15 个初态**所有成功分支**在判定窗口内曾经跌到
的最低运行分数,阈值 = 这些最低点的 **q 分位**。因此 q 是名义误报率,不是实测的。

**报警** — 连续 **K=3** 步低于阈值,一次锁存。

**判定窗口** — `STOP=35` 是唯一不含污染的设定:语料 B 最短的成功跑 35 chunk,所以窗口内
512 条全部存活,每条拿到的触发机会完全相同。见下。

## 今天做了什么(按顺序)

1. **从「离线整轨迹」转到「逐步放出前缀」** — 把 48 个离线统计量逐个因果化,在每个 t 上只用
   `c[0:t]` 重算。结论:**离线名次不能预测在线名次**(top5 重合 1/5),而且**离线越高掉得越狠**
   —— 离线赢家靠的是用总长度把「尾部窗口」摆在塌陷上。
2. **发现在线 AUC 排名同样不能用** — AUC 是组内配对,部署要阈值跨初态搬得动。
   `st·mean` 在线 AUC 第一但部署最差。**只能按部署指标本身选。**
3. **假装在线推理,逐条数对错** — 到第 40 步为止 88.9% 判对(基线 57.8%),16 种通道/规则
   配置全部落在 86.7%–88.9%,**两条通道合并没用**。
4. **扫滑窗宽度与跨 chunk 跨度** — 发现第 30 步先前测出的「几乎没信息」是**窗宽造成的**:
   W=8 稀释了刚开始的塌陷,换 W=2–3 得 85.5%,净增 +27.7 点。
5. **扫距离函数**(含用户提出的加权 Jaccard) — 六个连续距离秩相关 0.991–1.000,可互换;
   只有基于 top-4 的两个不同,而其中 `top4_mass` 对现象**没有响应**(自身塌陷比 0.998)。
6. **线性组合 ac·WJ + st·Hell** — +0.6 点。机制:**线性组合与滑窗可交换**,所以这和在
   chunk 层面先组合是同一件事。
7. **搜索放大器**(自参照 z 分 / CUSUM / 差分窗 / EWMA / 窗口前非线性跨通道,610 格) —
   **无一胜过朴素窗均值**。因为第 28 步之前就是基线,**没有历史可以累积**。
8. **量化信号的时间形状** — 单个 chunk 在第 29 步就给 78.3%,第 28 步只有 65.4%。
   边际价值 28→29 是 +12.9 点,30→31 只剩 +0.4。**信号是突变,不是弱而弥散。**
9. **发现判定窗口泄漏并回溯更正** — 同一配置从 t<35 到 t<52,检出 73.6% → 98.2%,
   而触发机会比从 1.00 变到 1.39。**当天第四次遇到同一个泄漏。**
10. **打开 token 轴** — 回应「ac 有 10 倍位点,信息量应该更大」。测下来:11 个 token 每个
    单独都是 73.6%–77.8%,所有跨 token 对比量塌到 16%–51%,11 维监督模型 ±0.01。
    相关矩阵呈**带状**(相邻 0.95,衰减到 0.75),有效维度 1–2。

## 与既有结论的关系

**延续并加强的**

- `route-change-is-one-factor`:本轮把「一个自由度」从**切法/聚合**推广到了**距离函数**
  (含非 f-散度的 Ruzicka)与 **token 轴**。整个张量在变化率读法下仍是一个量。
- `moe-churn-zero-lead-time`:第 28 步之前判对率 = 基线,**并给出了机制** ——
  所有依赖累积历史的放大器都失败,正因为没有前兆可累积。
- 归档 §3.2 / §6.1 的「未声明自由参数」:本轮又新增两个(**判定窗口 25 点、滑窗宽度 23 点**),
  而且它们比之前记录的任何一个都大。

**新增的**

- **token 相关矩阵的带状结构**是 VQ 账户到目前为止最直接的一次确认:action token k 的路由
  是对它自己那条噪声潜变量的量化读出,同 chunk 内相邻动作潜变量连续 → 读出相邻更像。
- **滑窗是同质化器**:`top4_mass` 逐 chunk 与 hellinger ρ=0.584,3 步窗均值后升到 0.869–0.915。
  这解释了归档里 646 种切法 + 13,494 种聚合为何全塌 —— **它们都在窗口之后比较**。

**范围说明**(按 `moe-only-scope`)

同日另一路 agent 测过匹配的物理量:在失败类型对比上它更高,且与路由均值秩相关 0.86/0.95。
记录于此,不改本文结论走向。
