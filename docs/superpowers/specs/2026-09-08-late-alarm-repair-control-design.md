## 0. 要回答的问题

用户假设 **H1**：抓得晚不是障碍；只要修复动作对，晚报警之后也能救回来。

到今天为止所有报警后干预臂改的都是采样、路由或 chunk 长度，没有一个改过物理状态，
所以关于"改物理状态的控制"是零证据。同时"晚"有三条伤害通道，必须分开测：

| 通道 | 含义 | 本实验如何分离 |
|---|---|---|
| 预算 | 原上限内剩余步数不够 | 主终点用修复后固定窗口，副终点用原上限 |
| 世界不可逆 | 物体掉落、移出可达范围、翻倒 | 按分叉时刻的物理类别分层 |
| 闭环与内部结构 | 策略无记忆，但策略与世界合成的闭环有吸引子；模型单次前向的路由结构可能已退化 | 分叉时刻作为操纵变量；修复前后各读一次内部结构；记录修复后是否重新陷入 |

用户已确认：终点采用 C，即修复后固定窗口为主、原上限为辅；控制器强度作为实验的一个轴。

## 1. 控制论框架

- **被控对象**：MuJoCo 世界加机器人，状态 x 含物体位姿、机械臂位姿、控制器插值状态。
- **反馈控制器**：VLA 策略 u = π(y)，y 为两路图像加 8 维本体感受。π 无记忆，输入无时间维。
- **故障**：闭环 x_{t+1} = f(x_t, π(y(x_t))) 进入任务进展为零的伪吸引子，价值 PPT 已把它分成不动点与极限环两类。没有零件坏，是复合映射有一个不是目标的不动点。
- **观测器与故障检测**：预警方法是残差发生器。kNN-20 读路由动力学到成功参照库的距离，v7/v8 读路由相对自身基线的冻结与湍流，物理规则读"闭合后物体是否随末端运动"。报警 = 残差持续越界。这一层已经做完，本实验不改任何阈值。
- **恢复 = 监督切换控制**：模式集合 {VLA, REPAIR}。守卫 g1：报警或预定分叉时刻，切到 REPAIR；REPAIR 是任务空间上的比例控制器 u = sat(K_p (x* − x))，夹爪命令固定为张开；守卫 g2：到达 x* 且稳定，或用满修复步数，切回 VLA。本轮每条后缀只允许一次切换，驻留时间为无穷，避免抖振问题混入。
- **被测量的对象**：VLA 在目标吸引子下的吸引域 R(T) = {x : 从 x 起 VLA 在 T 步内成功}。修复把 x_fork 映到 x*；救回当且仅当 x* ∈ R(T)。各臂只改 x* 的位置，臂越强 x* 越深入 R；分叉时刻越晚 x_fork 离 R 越远。实验沿"控制器强度"与"陷入时间"两条轴估计 R 的边界。
- **可达性与预算**：终点 A 测 x* 是否在 VLA 的预算受限吸引域 R(520 − s) 内；终点 B 测是否在 R(300) 内。两者之差就是预算通道。
- **能力域的观测器**：切回 VLA 后第一次前向的路由结构读数，检验它能否预测 x* ∈ R。这是用户提出的"内部结构不稳定"通道的直接检验。

## 2. 语料与分叉点

### 2.1 语料

`moe-trap-control` 的 Long 初筛 950 条 Pro/Plus 主轨迹，全部有精确 C0 重放、冻结 kNN-20/v7/v8/v8.2 首报位置
（`design/experiment_long_screen_summary_20260908/first_alarms.csv`）。

| 项 | 数 |
|---|---|
| 主轨迹 | 950，失败 381，成功 569 |
| 失败中 kNN-20 有报警 | 365/381，首报中位 q26，四分位 [16, 32] |
| 失败中 v8.2 有报警 | 308/381，中位 q31 |
| 成功中 kNN-20 误报 | 73/569 |
| 上限 | 520 步 = 52 个 chunk，所有失败都跑满 |

只取需要抓放自由物体的 7 个基础任务：KITCHEN_SCENE8、LIVING_ROOM_SCENE1、LIVING_ROOM_SCENE2 两种、
LIVING_ROOM_SCENE5、LIVING_ROOM_SCENE6、STUDY_SCENE1，失败合计 210 条。
抽屉、微波炉门、旋钮三个任务（SCENE3/4/6）的未完成子目标可能是铰接件，本轮排除并计数。

抽样：失败主轨迹按基础任务分层，每任务按 `stable_id` 哈希取前 7 到 8 条，要求 kNN-20 报警存在且 q ≤ 44，
共 **50 条**；另取 kNN-20 误报的成功主轨迹 **15 条**，同样分层，用于估计破坏率。
选样只读"失败/成功"与报警时刻，不读任何分支结局。

### 2.2 分叉时刻

每条失败主轨迹最多三个分叉点，全部由 C0 精确重放到该 query 的推理前状态并持久化快照：

| 时刻 | 定义 | 来源 | 存在条件 |
|---|---|---|---|
| early | 首个满足抓取自检物理规则的 query：夹爪已闭合，末端离闭合位置 ≥ 0.10 m，目标物体自闭合起位移 < 0.01 m | `analysis_trap_taxonomy` 的 phantom 定义 | 只在 phantom 类主轨迹存在 |
| mid | kNN-20 首报 q + 1，可部署时机 | 与 09-08 自适应控制一致 | 365/381 |
| late | 固定 q = 44，剩余 80 步 | 与检测器无关的"晚" | 全部 |

v7、v8.2 的首报 q 记为协变量，不作分叉点。成功主轨迹只在 mid 分叉。

### 2.3 物理类别

每个分叉点用快照的 `observable_cache` 与 `preflight_q000` 计算，冻结在分析前：

| 类别 | 判据 |
|---|---|
| untouched | 未完成目标物体自初始位移 < 0.02 m，直立，未被抓持 |
| displaced_reachable | 位移 ≥ 0.02 m，仍在桌面工作区内、直立 |
| dropped_or_tipped | 高度低于桌面或倾角 > 45°，或离末端 > 0.60 m |
| in_hand | 目标物体正随末端运动 |
| articulated_pending | 未完成目标是铰接件 |

未完成目标由 `env.env.parsed_problem["goal_state"]` 逐条 `_eval_predicate` 得到，取第一个未满足谓词的可动物体。

## 3. 臂

每个分叉点每臂 2 次重复，策略噪声与环境噪声按现有 `seed_for` 配对。

| 臂 | REPAIR 阶段 | 回答什么 |
|---|---|---|
| A0 same_noise | 无，即 C0 重放本身 | 分叉忠实度锚点，必须逐位复现主轨迹 |
| A1 new_noise | 无，candidate0 换噪声续跑 | 诚实基线 |
| A2 open_only | 夹爪张开、位置不动 1 个 chunk | 只重置"抓住了"的信念够不够 |
| A3 retract_history | 张开，比例控制回到最近一次闭合前最后一个开爪 query 的末端位姿；若从未闭合则原地抬升 0.10 m | 用户说的"回退机械臂"，不用任何物体信息 |
| A4 retract_above_target | 张开，比例控制到目标物体当前位置正上方 0.10 m | 特权位姿下的最小修复上限 |
| A5 retract_above_target_noisy | A4 的目标在 xy 加 N(0, 2 cm) 噪声，按重复配对 | 部署时定位误差的容忍度 |
| A6 scripted_regrasp | A4 后下降到抓取高度、闭合 1 个 chunk、抬升 0.08 m，再交回 | 阳性对照：外部控制器完成抓取，VLA 只做搬运 |

REPAIR 控制器：u_t = sat(K_p (x* − x_t))，作用在 LIBERO 的 7 维动作 [dx, dy, dz, drx, dry, drz, g]，
旋转分量为零，g = −1 张开。K_p 与每步最大位移在 P0 上标定，要求 0.10 m 的回退在 3 个 chunk 内完成。
守卫 g2：‖x − x*‖ < 0.02 m 连续 5 步，或 REPAIR 已用 6 个 chunk。A6 的抓取高度取物体 geom 包围盒中心高度，
抬升后若物体高度增加 < 0.02 m 记 `scripted_grasp_failed`，仍交回 VLA 并保留结果。

交回后 VLA 使用该重复的新噪声流，10 步 chunk，不再触发第二次修复。REPAIR 阶段不调用模型，不产生路由记录。

## 4. 终点

| 终点 | 定义 |
|---|---|
| B，主 | 自分叉起 300 步内 `check_success` 为真；REPAIR 步数计入窗口 |
| A，副 | 原上限内成功，即分叉后 520 − s 步内 |
| 复陷 | 交回后按冻结的 stagnation 规则连续 5 个 chunk 无进展，或再次满足 phantom 规则 |
| 破坏 | 成功主轨迹上，分支未成功 |
| 修复阶段诊断 | 到达 x* 的步数、末端终误差、A6 的抓取是否成功 |

环境创建时 horizon 设为 520 + 11 + 300，使 late 分叉也能跑满 300 步窗口；主轨迹与 C0 不受影响。

## 5. 内部结构读数

在分叉前最后一个 VLA query（取自主轨迹记录）与交回后第一个 VLA query 各算一次，全部由单次 `hb_router_probs[8,10,11,32]` 得到：

1. state token 在 L2 到 L5 的 top-1 概率与熵，即 pose code 的锐度。
2. action token 弧的 bandedness 与到语料模板的 Procrustes 距离，复用 `moe-token-geometry-0906/experiments/arc_lib.py`。
3. 交回后累计 8 个 query 时的 kNN-20 距离，复用冻结参照库。
4. v7 的 z_F，monitor 从主轨迹前缀继续更新。

分析前冻结的假设：这些读数在控制类别、时刻、臂之后仍预测救回，则"内部结构"通道成立。
