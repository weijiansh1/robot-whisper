# MoE routing phase portrait：跨实验综合

> 2026-09-04。协议 `PROTOCOL.md`（启动前冻结 + Amendment 1）。六组实验：
> E2 loop 时序 / E3 static / E4 复发与 lock-in / E5 内部相位 / E7 任务流形 / E8+E9 相图与 silent 边界。
> **物理只定义事件与标签，检测/分型/预测全程只读 MoE routing。**
> 语料：`grid50x8`（4 checkpoint × 10 任务 × 400 集 = 16,000 集，532 失败）+
> `main16x32`（5 任务 × 512 集，307 失败），均 paper-right，45/45 任务行↔集对账零失配。

---

## 一句话

**主命题成立**：loop 与 static 在 MoE routing 空间里是**不同且在门控维度上相反**的表型，合并必然抵消。
**但预设的时序剧本基本不成立**：不是「Disperse→Switch→Collapse」三段式，而是 onset 前 ~3 步的
**同时相变**；没有 collapse；复发是 lag-1 冻结而非 lag-k 循环；lock-in 亚型在这批数据里几乎不存在。
**最有价值的正面发现来自两个方法学互不相干的实验的交叉验证**：成败的区别不在"是否进入异常区"，
而在**"能否离开"**。

## 一、立住的（跨单位复现 + 预先声明）

### 1. routing 携带任务身份，且不靠场景布局（E7）

| suite | 1-NN LOEO 判别准确率 | 严格变体（排除同 task,scene 邻居） |
|---|---|---|
| goal / long / object / spatial | **100% / 100% / 100% / 100%** | 100% / 99.88% / 99.98% / 100% |

chance = 10%，四张混淆矩阵全为纯对角。**前 5 个控制步的深层路由就把任务身份写死了**；
goal 的 10 个任务共用同一厨房、只有指令不同，判别仍 100%。
这是"任务条件流形"假设的前提，成立后 wrong-manifold 才可判。

### 2. static 表型：变平 + 共识升 + 近饱和周期复现（E3）

三个预 named 单元全立（raw），且**表型在物理 onset 之前就已建立、贯穿始终**：

| 信号 @lead | −4 | −2 | **0** | +2 | 判定 |
|---|---|---|---|---|---|
| `S_ent`（变平） | +0.13/+0.19 | +0.18/+0.26* | **+0.33*/+0.35*** | +0.39*/+0.35* | 双单位立（残差不存活）|
| `S_margin`（尖锐度） | −0.23/−0.30* | −0.18/−0.25* | **−0.29/−0.31*** | −0.23/−0.25* | 与 S_ent 同向佐证 |
| `C`（共享支持集） | +0.36*/+0.39* | +0.32*/+0.41* | **+0.37*/+0.45*** | +0.33*/+0.39* | 双单位立（U2 残差存活 p=.010）|
| `min_{k≥2}mob_k`（周期） | −0.46*/−0.49* | −0.47*/−0.48* | **−0.49*/−0.50*** | −0.44*/−0.48* | **三单位立**，最强 |

（U1 main SCENE8 / U2 grid SCENE8；`*` = maxT p<0.05）
熵升**且**间隔降 → 确实是变平，不是单一指标的伪影。

### 3. loop 表型：onset 前 3 步的同时相变（E2）

预 named 五个单元 **4 个不立、1 个单单位**（详见 §二）。数据实际给出的是两个 SCENE8 单位一致的
**lead = −3 同时爆发**：

| lead=−3 | U1 (main) | U2 (grid) | 残差后存活 |
|---|---|---|---|
| `D_tok`↑（token 去同步） | +0.336 (p=.009) | +0.270 (p=.0245) | U1 (p=.0015) |
| `C`↓（共识降） | −0.298 (p=.0275) | −0.270 (p=.0245) | U1 (p=.0015) |
| `A`↑（路由加速） | +0.327 (p=.0115) | +0.347 (p=.0015) | U2 (p=.0020) |
| `V`↑（末段切换） | — | +0.307 (p=.0050) | U2 (p=.0255) |
| `S_ent`↓（门控尖锐化） | −0.206 (n.s.) | −0.264 (p=.033) | — |

**去同步、尖锐化、切换是同一瞬间的三个面。**「unstable commitment」（尖锐与切换并存）方向上得到
支持，但尖锐那条腿只有单单位。

### 4. loop 与 static 在门控维度方向相反（E2 × E3）

`S_ent`：loop@−3 **↓**（尖锐化），static@0 **↑**（变平）。
"两种 Trap 合并会抵消"这一判断，在第三、第四套语料上确认。

### 5. switching 象限强富集失败，lock-in 象限不富集（E4）

| 象限 | goal/object/spatial 组内 AUC | 覆盖 |
|---|---|---|
| **switching**（V,A 双高） | **0.74–0.77**（p≤.001，残差存活） | 失败 76–89% 落入 vs 成功基率 ~40% |
| **lock-in**（低动/尖锐/高粘） | 五单位**全 null** | 失败落入率 ≤ 成功基率 |

loop 失败富集 switching 成立（goal 23/24、object 25/28）；static 失败清楚分离（落 other/lockin）。

## 二、被数据否掉的（预设 vs 实测）

| 预设 | 实测 | 出处 |
|---|---|---|
| `Disperse → Switch → Collapse` 三段**时序** | **同时相变**：次序统计零结果，D_tok/V/A/C 首越时刻不可区分（符号检验 p≥0.23） | E2 |
| `C` 在 onset **后**升（同质化坍缩） | **方向相反**：C 的显著变化是 onset **前下降**（C@−3 双单位显著负）；onset 后不升 | E2 |
| `V/A@−2` 复现腿 | **时点特异失败**：三单位同向但 0/3 显著；峰在 **−3**（U2 V@−3 p=.005、残差 p=.026） | E2 |
| `S_margin@−2`↑ | 0/3 显著，U3 方向翻转 | E2 |
| 反复抓空 = **lag-k 周期脉冲列** | **lag-1 冻结**：失败集 best-k=1 占 93–95%，中位 cycle_gain 为负。反倒 object 的**成功**集 90.7% 是 k=3–4（取放节律） | E4 |
| **lock-in / 自信持续做错**亚型 | 几乎不存在：22 例 lock-in 失败中 16 例其实伴 static 事件，**真正无事件的候选仅 2 例** | E4 |
| loop 前的**相位停滞/倒退** | 方向对但功效不足：`osc`@−3/−2/−1 效应 +0.60/+0.62/+0.63，p=.056–.071，未过 maxT | E5 |
| 宏状态**驻留差**可检验 | 19 格族零结果：13 格可测中 10 格方向为正但仅 1 格过 maxT，不达复现门槛，**不作主张** | E8 |

## 三、"能否离开"——已降级（2026-09-04 事后修订）

> **本节原为"最重要的正面发现"，现降级为受混杂支配的描述性观察。**
> 三条互不相干的复核各自独立指向同一结论：原对比被 **onset 时点差与集长差**支配。
>
> 1. **`analysis_committor/` 离线复核**：原对比（onset 后带内占用 0.148 vs 0.382）在
>    **等窗 + onset 匹配**后收缩到 0.354 vs 0.450；同 cell 配对 28 格仅 18/28 同向
>    （p_sign=0.185），且 onset∈[20,40) 的两个箱符号**反转**。主因是自恢复 loop 的中位
>    onset=8 而致败 loop=31，加上集长差。
> 2. **原型 A 的臂 T 复核**：在 onset 窗 [−4,+8] 上，**纯集长臂 T 与 A 同向且 p 更小**
>    （0/2 vs 34/55, p=0.159；0/4 vs 28/62, p=0.102）。原因同上——致败 loop 的 onset
>    中位晚于恢复性，窗口对致败集开在更晚的绝对 q 上，正好罩住 T 的固定报警时刻。
>    **该窗不是时点中性的。**
> 3. **原型 B**：loop 通道 0/6 报警确实优于臂 C 的 2/6、臂 T 的 5/6，但 n=6，
>    只有一个单位显著，本就按描述性对待。
>
> **改用逃逸 committor 陈述同一件事**（功效充足）：`e_loop = 0.46` vs `e_static = 0.092`
> （Fisher p=1.8e−17）——**loop 是可逃逸的，static 基本不可逃逸**。这是同一现象的
> 时点中性表述，取代下文的带内占用对比。详见 `analysis_committor/REPORT.zh.md`。
>
> 以下原文保留作为记录，其结论**不可引用**：

两个方法学互不相干的实验，各自独立得到同一结论：

- **E4（脉冲对齐曲线）**：恢复性 loop（成功集里的瞬态 loop）在 onset 前有脉冲（z≈1.06@−1），
  随后**回落到参照带之下**（−0.8@+5）；致败 loop 全程 z≈0.8–1.1 **平台不回落**
  （main 致败在 +7 升到 2.2）。
- **E8（宏状态事件束）**：成功 loop 同样进入 switching 带，但 **onset 后迅速离开**；
  失败 loop 留在带内（pre-onset 占用 0.50–0.57 vs 基线 0.409）。

**「有没有进入异常区」两类共有；「能不能出来」才是成败之分。**
这直接回答了"MoE 能否区分暂时错误与真 Trap"——**机制上能，统计上尚未达复现红线**：
E4 的检验里 grid 合并腿 `cycle_gain`（p=.047）与 main `post_pulse_return`（p=.035）各过一格 maxT，
但**无一格在两语料同时存活**，且 `pulse_count` 受集长混杂（致败≈超时长集，n_queries AUC≈1.0）。

## 四、内部相位 φ̂：是相位，但只在晚期超越计时器（E5）

- **计时器证伪通过，仅 t=30**：同组同绝对 q 上失败 φ̂ 显著落后
  （main −0.056，12/13 组同向；grid −0.103，24/26 组同向；各 p=.0005）。t=20/25 无差。
- 成功集 Spearman(φ̂,q) 中位 **1.000**（φ̂ 在健康轨迹上就是一只完美的钟），失败集 0.72–0.83。
- 失败的相位推进变慢：`v̂`@t30 det AUC **0.690 / 0.783 / 0.786**（三单位同向，前两者 p=.0005），
  伴 `stall`↑、`regress`↑（各两单位显著）。
- **slow-normal 判据是 v̂ 的符号，不是 stall**：v̂>0 比例 快成功 0.976 ≳ 慢成功 0.957 ≫ 失败 0.694；
  而慢成功与失败在 `stall` 上分不开（p≥.095）。慢成功没有离开健康流形（d_healthy 慢−快 ≤0.003）。

## 五、可观测性边界与新颖性边界（诚实条款）

### MoE-silent 很罕见，但"不可评"更常见（E9）

839 个失败集：**20 silent / 470 detectable / 349 not_evaluable**。
- silent 占可评失败 **4.1%**，每个套件都**低于成功集的 FP-silent 底座**（合计 12.3%；
  可交换零假设期望 ≈60，实际 20）→ 失败集系统性偏离，**MoE-silent 亚群规模上限被压在判据噪声之下**。
- 但 **41.6% not_evaluable 全部源于参照贫乏**（失败富集组的同组成功 <5，SCENE8 两语料占 185/349）。
  所以结论是"**MoE-silent 很罕见**"，不是"不存在"。
- 双口径稳健 silent 仅 **2 个集**（grid/spatial，已列清单）。
- **"detectable" 标签近乎空洞**：87.7% 的留一成功集也会被判 detectable；只有 "silent" 是强标签。

### 多数腿扛不住既有基线的残差

对 `mob1_w8`（= 既有最强 train-free 基线 d9+Hellinger+W8）做组内秩残差后**仍存活**的只有：
E2 的 −3 处 `D_tok`/`C`（U1）与 `V`/`A`（U2）、E3 的 `C@0` 与 `min_mobk`（U2）、
E5 的早期 `d_healthy`（main，全表唯一三时点稳定存活）、E4 的 switching 象限。
**其余大部分（含 E3 的变平、E5 的 v̂/stall）被旧变化率吸收，不能宣称独立新信号。**

### 在线报警：误报底座是硬约束（E4）

`z>2` 单脉冲在**干净成功集**的触发率 **24–81%/集**——按此阈值在线报警不可用。
唯一低底座特征是 pulse **train**（短套件 0.1–1.4%、main 3.0%），但 long 达 10.6% 且判别力弱。

### 负对照兑现

`D_layer`（层间不一致）在 E9 中只占 max-偏离的 **1.9%**，在 E2 中仅单单位显著且残差不存活——
与既有"cascade 层间延迟全 0、各层同时投影同一因子"的结论一致，负对照按预期退化。

   **本报告不裁决**，按 E3 的直接测量陈述 §一.2，并把冲突原样记录，待一次针对性复核。

## 七、方法学收获（会外溢到别的工作）

1. **loop 的定义离不开物体位置**：只用 eef+夹爪的降级代理 specificity 仅 0.08——
   正常的"取放-返回"与病理循环无法区分（93% 成功集被误标）。
   obj-aware 代理（`sim_layout.json` 具名槽位）在 SCENE8 双语料 **912/912 与完整代理全等**后方准入。
2. **冻结的 loop 规则对非 free-joint 被操纵对象有语义盲区**：转旋钮（KITCHEN_SCENE3）、
   开抽屉（middle_drawer）的成功集触发率 63%/13–16%，其 loop/trap 通道判无效（static 不受影响）。
3. **成功集里的瞬态 loop 是免费的负对照人群**（grid 538 + main 100），
   E4/E8 的"能否离开"结论全靠它。
