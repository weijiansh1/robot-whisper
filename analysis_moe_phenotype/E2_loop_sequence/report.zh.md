## 3. 家族内（56 格 maxT 校正后）其余显著格——非预 named，如实列出

- **U2 raw**：V@−3 +0.307 (p=0.005)；A@−3 +0.347 (p=0.0015)；A@−4 +0.265 (p=0.032)；

  **U3 resid**：无显著格。
- 读法（诚实）：SCENE8 两单位的 loop 前兆是真实存在的（V/A/D_tok 升、C/S_ent 降），
  但**峰值在 lead −3 而非冻结的 −2**：A@−3 在 U1+U2 raw 同向显著、U2 残差也存活
  （p=0.002），V@−3 在 U2 raw+残差存活、U1 p=0.064 差半步。预 named 时点差一格导致
  复现腿形式上不立——这是时点特异性失败，不是信号缺席。U3 的 V/A 升高显著格挪到了
  lead 0，时序整体后移（可能与两物体篮筐任务的 loop 语义或 objaware onset 无真值校准
  有关，见 §6）。C 的显著变化方向与新腿 c 相反：**consensus 在 onset 前（−3）即显著下降**
  （U1 残差 p=0.0015），与 D_tok 升同期镜像；onset 后无任何单位出现 C 回升。

## 6. 边界与功效

1. **U3 代理等级**：proxy_grade=objaware——与 full 的等价性只在 SCENE8 上实证
   （512/512、400/400 零不一致），5 个池化任务无物理真值。按冻结口径只取**失败集**
   事件（56），27 个成功集 loop 标签集两侧排除（"良性重试 vs 假阳性"不可判）。
2. **红旗排除**：KITCHEN_SCENE3 与 open_middle_drawer 的 loop/trap 通道无效
   （铰接机构盲区，AUDIT §7.1/§8.4），未进入 U3；KITCHEN_SCENE6（loop 无失败集事件）、
   KITCHEN_SCENE4/STUDY_SCENE1（0 loop）按事件预算自然缺席。
3. **功效**：U1 只有 10 个有事件组（sign-flip 分辨率受限）；U3 每组事件中位 1–3 个、
   残差腿再失 ~16% 事件；U2 对照侧每组 ≤8 集。0.09–0.23 量级的效应在此功效下不显著
   属预期，判定按冻结标准执行、不放宽。
4. mob1_w8 在 q<8 无定义；三单位 onset 均 ≥6 且中位 ≥26，残差腿损失主要来自组内层
   样本 <3，不来自 q<8。

## 7. 结论（诚实条款）

SCENE8 两个独立单位存在可复现的 loop 前兆表型：**onset 前 ~3 个 query 处 V/A/D_tok/
D_layer 升、C/S_ent 降**；其中 A@−3（U2 残差 p=0.002）与 D_tok@−3（U1 残差 p=0.0015）
在残差腿至少一个单位存活。但按冻结的预 named 时点与判定标准：复现腿 V@−2 不立、
A@−2 单单位；新腿 a 因次序零结果与 U3 缺席不立；新腿 b 不立；新腿 c 方向相反
（C 下降且前置）。U3（objaware 池）的时序整体后移至 onset 处（V/A/flow_com@0 显著），
与 SCENE8 的 −3 前兆不同相——跨单位时序不一致本身是本实验最值得记录的负结果。
