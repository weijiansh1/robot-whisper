## 3. 载荷主张：两条对照（臂 C = mob1_w8，臂 T = 平凡集长）

三臂跑**同一批 episode**、同一套 z、同一个 `q_min`，集长/暴露史/存活偏倚完全相同。

### 3.0 臂 T 是什么，以及它作废了哪个口径

**臂 T = 与臂 A 完全同结构的状态机，一级信号换成集内 query 序号 q（不读任何 MoE）。**
loop 腿用 `z(q) > θ_enter^T`（"集跑得久"，与 A 同侧）、`z(q) < θ_exit^T` 回落；
static 腿用 `z(−q) < θ_s^T`（与 A/C 的 θ_s 完全同分位规则）。
臂 T 读不到 MoE，static 通道的二级腿（token_consensus）无从替代 → **只剩一条腿**
（单腿比合取**更容易**响，不削弱 T）。持续腿按同一条"10% 健康尾"规则重定：
**K_T = 5、M_T = 6**（两单位独立各自也都给 5 与 6）。另报旋钮值与 A 相同的 T-sameknobs。

### 3.1 匹配视界的对角线检验（**改锚后的载荷结果**）

（共同视界 T = min(onset, n_q(succ)−1)）。因此**任何纯粹由 q 决定的报警器必然满足
`mh_det ≡ mh_fa`** —— 它对配对的两集同时命中或同时不命中。
于是"margin = mh_det − mh_fa > 0"就是**扣掉钟以后剩下的判别力**。

2. **static 通道在冻结点是死的**（§4）。合取两条负相关的腿，在事件人群上的联合率
   （0.3%/0.7%）比健康人群（3.3%/3.6%）**还低**。设计错误，不是功效问题。
3. **"能否离开"的证据被臂 T 收回**（§2.5）。onset 窗 [−4,+8] 不是长度/时点中性的
   （致败 onset 中位 43/41 vs 恢复性 40/32），臂 T 在同一窗上同向且 p 更小。
   本方案对这条核心命题**没有贡献任何独立支持**。
4. **提前量不够**（§2.2）。loop 报警中位 −2 / **+1**，只有 52%/47% 早于 onset。
   消融臂 C 在这一项完胜（−3/−9，92%/86% 早于 onset）。
5. **检测器有一部分是钟**（§5）。误报中位 q=35、距集尾 4 步；截断到 q≤38 后
   det_loop 掉到 .509/.484。臂 T 把这部分的规模量化了：q>38 那一段几乎全部是钟。
6. **正面结果的绝对量级很小**（§3.1）。匹配视界 margin 中位只有 +0.108/+0.139，
   最大 +0.16。它足以支持"MoE routing 有增量信息"，**远不足以支持"这是个可用检测器"**。
7. **loop 通道无稳定工作点**（§6.3.1）。三个旋钮任意一个动一格，误报跨两个数量级
   （尽管匹配视界 margin 的符号稳定）。
8. **恢复性 loop 只有 2+4 集**（§2.5），不能靠留出集补。任何 p 值都是装饰。
9. **分型只在冻结点之外兑现**（§3.3）。冻结点上臂 A 与臂 T 一样是常数分类器
   （平衡 0.500）；要拿到 0.674–0.799 必须把 θ_c 松到 p70 以下，而那不是冻结规格。
10. **P1b 有 1.9%/2.6% 的报警随全局标签置换而变**（§1.1）。CONSTRAINTS §1 强制的
    成功集 LOGO 校准的固有抖动；留出集上若成功集偏小，阈值噪声会直接进报警。
11. **z 池化 over q 是被迫的**（§5.2）。逐 q 参照在事件时点不存在（E9 §6.6）。
12. **无事件失败也被大量报警**（.929/.750），分型无真值可验。
13. **static 侧的提前量分位数基于 n=0 与 n=1**，不应引用。
14. **对齐工作点仍有残差**（§3.0 / §3.2 的 ⚠ 行）：臂 C 的 loop FA 封顶 .165/.152、
    臂 T 的 FA 曲线在 .019 与 .327 之间跳空，多个格的 Δ 同时含召回差与工作点差。
    §3.1 的对角线检验不受此影响（它沿各臂自己的整条曲线统计，不需要对齐）。
