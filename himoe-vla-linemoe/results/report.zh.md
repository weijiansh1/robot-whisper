# 失败轨迹上的 chunk：flow 去噪还直不直

> 2026-09-03。设计与判据见 [../PREREG.md](../PREREG.md)，采集启动前冻结；8 个信号的定义
> 直接沿用 `analysis_flow_straightness/` 在**无标签**语料上已算过的那套，一字未改。
> 2000 次 episode 级组内标签置换，maxT 同时校正 8 信号 × 3 时点 = 24 个单元，seed 20260903。
> 不训练分类器、不拟合 PCA/probe、不从评估集调阈值。

## 一句话结论

**线还是一样直，但"决定"在末段抖得更厉害。**

失败 chunk 的几何曲率与成功 chunk 没有可测差别（路径/弦长 1.00302 vs 1.00255，
逐组同向仅 6/9，不显著）。真正分开的是**终点猜测在最后 5 个去噪轮里的漂移量**：
失败比成功高 **23.7%**，9 个配对初态里 8 个同向，组内配对 det AUC **0.823**，
联合 maxT **p=0.0125**；对既有 `route_mobility_w8` 做组内秩残差后仍是 **0.810 / p=0.0255**。

即：模型卡住时，**不是"一路犹豫地绕着走"，而是"路径照样笔直，但直到最后几轮还在改终点"**。

## 主检验：固定时点、组内配对 AUC

`det AUC` 只表示可分性；`p` 为 24 单元联合 maxT；`res` 为对 `route_mobility_w8`
做组内秩残差后的同一检验。

| signal | t=20 det / p | t=25 det / p | **t=30 det / p** | **t=30 res det / p** |
|---|---:|---:|---:|---:|
| `xhat_drift_late` | 0.582 / 1.000 | 0.557 / 1.000 | **0.823 / 0.0125** | **0.810 / 0.0255** |
| `xhat_travel` | 0.646 / 0.885 | 0.570 / 1.000 | 0.797 / 0.0325 | 0.772 / 0.0995 |
| `xhat_drift_mean` | 0.570 / 1.000 | 0.532 / 1.000 | 0.785 / 0.0530 | 0.759 / 0.1364 |
| `path_over_chord` | 0.532 / 1.000 | 0.608 / 0.996 | 0.671 / 0.720 | 0.696 / 0.545 |
| `cos_min` | 0.519 / 1.000 | 0.608 / 0.996 | 0.658 / 0.811 | 0.633 / 0.941 |
| `cos_chord_mean` | 0.506 / 1.000 | 0.620 / 0.980 | 0.658 / 0.811 | 0.671 / 0.753 |
| `speed_ratio` | 0.582 / 1.000 | 0.633 / 0.918 | 0.532 / 1.000 | 0.519 / 1.000 |
| `grip_flip` | 0.519 / 1.000 | 0.500 / 1.000 | 0.538 / 1.000 | 0.532 / 1.000 |

**24 个单元里，原始与残差两关都过的只有一个：`xhat_drift_late @ t=30`。**
`xhat_travel` 只过原始关；`xhat_drift_mean` 原始就是边缘（0.053）。三个曲率信号一个没过。

## 方向与逐组一致性（t=30，限于 9 个配对初态）

| signal | 成功中位 | 失败中位 | 变化 | 逐组同向 |
|---|---:|---:|---:|---:|
| `xhat_drift_late` | 0.02302 | 0.02848 | **+23.7%** | **8/9** |
| `xhat_travel` | 0.12574 | 0.16052 | +27.7% | 8/9 |
| `xhat_drift_mean` | 0.02657 | 0.03239 | +21.9% | 8/9 |
| `path_over_chord` | 1.00255 | 1.00302 | **+0.0%** | 6/9 |
| `cos_min` | 0.98948 | 0.98759 | −0.2% | 3/9 |
| `cos_chord_mean` | 0.99750 | 0.99694 | −0.1% | 3/9 |
| `speed_ratio` | 0.98161 | 0.97437 | −0.7% | 3/9 |
| `grip_flip` | 0 | 0 | 0 | 0/9 |

**曲率三兄弟的差异在小数点后第三位**：失败 chunk 的路径依然只比直线长 0.30%
（成功 0.26%）。作为对照，`analysis_flow_straightness` 在两批无标签语料上量到的是 0.19%–0.25% ——
失败并没有把这条线掰弯。

夹爪在成功和失败上都是 **0 次翻号**：卡住时模型对开合的决定同样毫不犹豫。

## 对照：这不是旧信号的改写

同一时点、同样组内配对，三个既有 train-free 量：

| control @ t=30 | det AUC | 逐组同向 |
|---|---:|---:|
| `route_mobility_w8`（d9 + Hellinger + W8 基线） | 0.557 | 5/9 |
| `action_change` | 0.544 | 5/9 |
| `action_magnitude` | 0.709 | 3/9 |

`xhat_drift_late` 的 0.823 高于全部三个，且在对 `route_mobility_w8` 做组内秩残差后仍存活
（0.810 / p=0.0255）。**这是一个动作空间的新量，不是路由变化率的另一种写法。**

> 注意：`action_change` 的池化中位数在成功/失败间差 86%，但逐组同向只有 5/9、det AUC 0.544。
> 池化中位数被 7 个全失败初态带偏，与组内配对结论不可互换 —— 本报告一律以组内量为准。

## 描述性：越到后面越不定（成功集同样如此）

每集头 8 个 chunk vs 尾 8 个 chunk：

| signal | head8 | tail8 | 上升集数 |
|---|---:|---:|---:|
| `xhat_drift_late` | 0.01228 | 0.02444 | **128/128** |
| `xhat_drift_mean` | 0.01402 | 0.02701 | 126/128 |
| `xhat_travel` | 0.07047 | 0.14805 | 120/128 |
| `path_over_chord` | 1.00194 | 1.00429 | 124/128 |
| `cos_min` | 0.99050 | 0.98450 | 6/128（即 122/128 下降）|
| `grip_flip` | 0 | 0 | 1/128 |

漂移在**每一集**都上升，包括 35 集成功。所以"末段更不定"是**时间效应**，不是失败标志；
主检验在固定控制步上比较，已经控制掉它。两件事都成立：整体越到后面越不定，
且在同一时刻上失败的更不定。

## 边界

- **单任务单 checkpoint**（long/t08），128 集，`checkpoint-right`。只能排除大效应，是先导不是确认。
- **7/16 初态全失败**，主检验实际只用到 72 集。这压低了功效，也意味着结论只覆盖"有结局方差"的初态。
- 唯一存活的单元在 **t=30 一个时点**上；t=20/25 全不显著。这更像"接近卡死时才出现"而非早预警。
  是否早于物理 loop onset，本报告**没有回答**。
- Onset 对齐没做：trap 工作那个经稠密真值验证的 loop/static 代理需要**物体位置**，
  而 `rollout_flow_lead.py` 只记录 8 维本体状态。补齐是给 collector 加几行的事，本轮未做，
  因此不用弱代理去冒充它。
- `xhat_drift` 是比 `path_over_chord` 灵敏得多的曲率探针（方向变化的一阶量 × t 放大，
  vs 路径长的二阶量）。所以严格说法是"弯曲量极小但可测，且只体现在末段"，
  不是"完全没弯"。
- 与 `analysis_flow_straightness` 的两批语料同为 `checkpoint-right`，可同表；
  与 right-50x8（paper-right）**不可**。
