## 1. 数据与单位

- 特征：仅 `artifacts/layer-expert-load/*.npz`，`action_load` 与 `state_load`，
  各 `[N_query, 8, 32]`。层索引 0-3 = 前段 L2-L5，4-7 = 后段 L12-L15。
- 推理时可见：路由载荷 + 当前 query index + 任务名。
  **不可见**：本体感觉、仿真状态、episode 长度、outcome、任何未来 query。
- `artifacts/features-full40-v2/*.npz` 只用来取 episode 元数据
  （`success` 用于划定标定集，`init_state_id` 用于分组，`flow_noise_seed` 用于事后对齐标签），
  不进入任何特征。
- episode 的 query index 已验证为 0..L-1 连续，t_max = 52。

## 2. 变换（预注册，不做事后挑选）

一个 (channel, layer) 的 32 个数是概率向量。距离一律在变换后的空间里算。

- 主配置用 **CLR**（中心化对数比）：`clr(p)_e = log max(p_e, 1e-6) − mean_e' log max(p_e', 1e-6)`。
- 备用配置用 **sqrt**：`sqrt(p)`，其 L2 距离即 Hellinger 距离（差一个常数因子）。

`1e-6` 的下限：实测全语料 `action_load` 最小 1.1e-2、`state_load` 最小 1.38e-5，
下限基本不生效，只为防 log(0)。这条是数值保护，与标签无关。

## 3. 排列不变性（硬约束）

专家在层间可独立置换，因此**永远不计算 a 层 32 维向量与 b 层 32 维向量之间的距离**。
全部距离都在同一个 (channel, layer) 组内计算，得到 16 个分量；
16 个分量各自标准化到自己的单位之后才做平均。

## 4. 检测器 1：自参照漂移（CUSUM）

对每个 episode，仅用它自己的历史：

1. 基线均值 `B[g] = mean_{q<W} x_q[g]`，g 为 16 个 (channel, layer) 组之一。
2. 基线离散度 `σ[g] = sqrt( mean_{q<W} ||x_q[g] − B[g]||² )`。
3. 距离 `d_q[g] = ||x_q[g] − B[g]||`，自归一化 `D_q[g] = d_q[g] / max(σ[g], σ_floor[g])`。
   `σ_floor[g]` = 标定折**成功** episode 的 `σ[g]` 的 5% 分位数，纯数值保护，
   防止基线窗口近似静止时除爆。会报告该下限被触发的比例。
4. 标量分数 `D_q = mean_g D_q[g]`（或指定子集 g）。
5. CUSUM：`S_q = max(0, S_{q−1} + D_q − k)`，从 q = W 开始，`S_{W−1} = 0`。
6. 首次 `S_q > h` 时报警。

- **k（松弛量）**：标定折成功 episode 在 q ≥ W 的 `D_q` 的分位数。
  主配置取**中位数**（q50）；配置 C 取 q75。这是从成功集算的，不看标签。
- **h（报警高度）**：由成功集虚警预算给定，见第 6 节。

## 5. 检测器 2：成功带（SAFE 式）

1. **按任务的早窗标准化**：对任务 T，用**标定折的成功 episode** 在 q < W 的行，
   逐坐标算 `μ_T[g,e]`、`s_T[g,e]`（`s` 下限 1e-4）。
   任意 episode 的任意 query：`z = (x − μ_T) / s_T`。
2. **组内偏离幅度**：`M_q[g] = sqrt( mean_e z_q[g,e]² )`。
3. **跨任务合并的时变带**：对每个 query index q，用标定折成功 episode 在 q 上的
   `M_q[g]` 取中位数 `m_q[g]` 与 1.4826×MAD `w_q[g]`（下限 1e-3）。
   合并跨任务是**在按任务标准化之后**才做的。
4. **覆盖判定（关键）**：query index q 被判为"有覆盖"当且仅当
   标定折成功行数 ≥ **50** 且贡献任务数 ≥ **8**。
   不满足则该 q **拒绝打分**（abstain），检测器在该 q 上不可能报警。
   **禁止**在覆盖耗尽后退回到某个 pooled 分布继续打分——这正是本项目上一次踩的坑。
   50 与 8 是先验设的保守值（约对应 pooled 样本量掉到千分之二以下、任务数掉到 1/5 以下），
   不是按检出率调出来的。
5. `G_q = mean_g (M_q[g] − m_q[g]) / w_q[g]`；
   连续 **2** 个有覆盖的 query 都超过 h 时报警，报警时刻记为第二个。
6. 同时报告"同任务同时刻成功参考"的覆盖率：
   失败 episode 的 query 中，其**本任务**在该 q 上标定成功 ≥ 5 个的比例。

两个检测器都从 q ≥ W 起才允许报警。

## 6. 阈值：只由成功集虚警预算决定

对每一折：标定集 = 训练折的**成功** episode；评测集 = 测试折的全部 episode。

- `h` = 标定折成功 episode 的"每 episode 峰值统计量"的 (1 − FPR) 分位数。
  分母包含**全部**标定成功 episode，太短而无法产生统计量的按"不报警"计入分母，
  所以名义预算就是标定集上实际实现的虚警率。
- 预注册的三个工作点：**FPR = 1%、5%、10%**，主报 5%。
- 阈值只在标定折上定，报出的 FPR 在**留出**测试折的成功 episode 上量。

## 7. 划分

- 5 折，**按 `init_state_id` 分块**。同一 init state 的兄弟噪声种子必然同折，
  绝不跨越标定/评测边界。
- 随机种子 20260906。

## 8. 零假设（与真实数并排报，缺一不可）

- **(a) 层内专家坐标置换**：对每个 (query, channel, layer) 独立打乱 32 个专家坐标。
  固定置换对组内距离完全不变，所以必须逐 query 打乱：保留"这一层有多尖"，
  摧毁"是哪个专家在亮、和上一帧是不是同一个"。整条流水线在置换语料上**重新标定**。
- **(b) clock-only 报警**：在固定 query index q\* 报警，q\* 取满足
  "标定折成功 episode 中长度 > q\* 的比例 ≤ 目标 FPR"的最小 q。
  这是"失败跑满 horizon、成功几乎都提前结束"这一长度混淆单独能买到的东西。
  **任何打不过 clock null 的结果都不算结果。**

## 9. 评测（冻结之后一次性读标签）

- 检出率：775 个带脱手标注的失败 episode 中报警过的比例。
- 偏移：`alarm_q − release_q`，报**逐 episode 偏移的中位数**（不是分组中位数的中位数），
  并给完整分布（5/10/25/50/75/90/95 分位、直方图、±2 内、±5 内、提前报警比例）。
- 留出成功 episode 的虚警率（同一冻结阈值）。
- 逐折与逐任务的散布，不只报合并均值。
- top-1 式的"整条轨迹取最大"不用于本次；本次全部是**首次越界报警**，因果、在线可实现。
  （唯一的离线成分是评测本身。）

## 10. 通道 / 层归因（只用无监督分解）

- 把检测器 1 限制到子集重跑，各自重新按同一 FPR 预算定阈：
  两个通道各自、前段/后段各自、以及 16 个单组各自。
- 报警时刻各分量在总分中的份额（对失败与成功分别统计）。
- 不使用任何有监督重要性排序。

## 11. 预注册的三个配置（全部报告，不挑最好的）

| 配置 | 变换 | 基线窗口 W | CUSUM 松弛 k | 其余 |
|------|------|-----------|--------------|------|
| **A（主）** | CLR | 5 | 标定成功集 q50 | 如上 |
| **B（变换敏感性）** | sqrt | 5 | 标定成功集 q50 | 同 A |
| **C（更保守的累加器）** | CLR | 3 | 标定成功集 q75 | 同 A |

三个都跑、都报。**A 之所以是主配置，是因为它写在这张表的第一行，不是因为它的结果好。**
不做任何基于检出率 / 精度 / 偏移的挑选。若将来需要在三者中选一个上线，
选择准则只能是留出**成功**集上的量（例如虚警率的折间稳定性、覆盖率），绝不能是标签量。

**冻结前评估过的配置数量 = 3**（就是上表这三个），信息来源 = 指令给的规格 + 语料的
无标签数值性质（载荷取值范围、有效秩、每 query 存活的成功数）。除此之外没有别的候选，
也没有做过任何"跑一批再挑"的动作。
