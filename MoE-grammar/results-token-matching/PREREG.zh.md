# 预注册:token 匹配图(state↔action、前层↔后层、沿 flow)

写于查看任何结果之前。本轮此前九个检测量全部在更严格的对照下失效,失效原因无一例外是
**指标或对照的设计**,不是模型。因此本文件先把量、对照、证伪条件写死。

## 0. 为什么是这个对象

现有特征把 token 之间的关系压成了一个标量:

```python
token_distance = _hellinger_from_bhattacharyya(token_bc)    # 11x11
soft_consensus = 1.0 - _mean_upper_triangle(token_distance)  # -> 标量
```

`11x11` 的 token 共路由矩阵被取了均值。**state 与 action 的区别、以及层与层之间的对应关系,
都在这一步被平均掉了。**

关键的方法学理由:每层的 32 个 expert 可以独立重排而模型函数不变,所以跨层比较 expert
编号无意义(这正是已修复的 `layer_disagreement` 缺陷)。但 `11x11` 共路由矩阵问的是
"哪些 token 被路由到一起",**天然置换不变**,因此前层的矩阵与后层的矩阵可以直接比较,
不需要任何 expert 对齐。

## 1. 数据与坐标

`hb_router_probs`:`[query, 8 层, 10 flow, 11 token, 32 expert]`。
层 = L2/L3/L4/L5(前)+ L12/L13/L14/L15(后)。
**token 0 = state,token 1..10 = action**(依据 `candidate_reranking.py:92` 的 `[..., 1:, :]`)。

对每个 `(query, 层 l, flow f)`,令 `p_i` 为 token i 的 32 维路由分布,
`M[i,j] = sum_k sqrt(p_i[k] p_j[k])`(Bhattacharyya 系数,置换不变)。

## 2. 预先声明的量(不再增加)

每个 `(query, l, f)`:

- `sa_coupling = mean_{j=1..10} M[0,j]` —— state 与 action 的耦合
- `aa_coupling = mean_{1<=i<j<=10} M[i,j]` —— action 内部一致性
- `sa_gap = aa_coupling - sa_coupling` —— state/action 分裂

每个 `(query, f)`,跨层匹配(对 55 个上三角元素取 Pearson 相关):

- `front_back = mean_{a in 前, b in 后} corr(vec M[a,f], vec M[b,f])`
- `within_front`、`within_back` —— 同组参照

沿 flow 的汇总只用三个:`f=0` 的值、`f=9` 的值、以及跨 10 步的最小二乘斜率。
**不做 early/mid/late 分箱**,因为 `moe-flow-semantics-0906` 已证明非终点步携带终点步没有
的信号,分箱会抹平它。

## 3. 机制侧(问题 A)

**A1 存在性**:上述量在 dev 与 external 两套采样设计上是否同向复现。
判据:符号一致 + 逐任务方向一致比例。

**A2 失败前是否形变**:在"chunk q 时仍在运行"的条件下做任务内 AUC。
这一条件精确抵消生存基率,是本目录反复踩坑后确认的唯一正确条件化方式。

**证伪**:若 dev/ext 符号不一致,或任务方向一致比例接近 50%,则该量不作为机制结论。

## 4. 检测侧(问题 B)

**基线不是"无信息",而是秒表。** 因为 1,442/1,442 个失败跑到 horizon、34,656 个成功只有
129 个跑到,长度几乎完全决定 outcome;任何不含长度基线的检测数字都不可解释。

嵌套顺序:`root -> 时钟 -> 时钟+任务 -> +本量`。任务身份由因果 routing 前缀推断,
在线不读 task ID。

**三个对照全部要跑,因为本轮证明单一对照会在两个方向上骗人**:

1. `(task, query)` 单元内逐点打乱 —— 破坏 episode 身份,但也破坏自相关
2. 同任务同长度的整条轨迹互换 —— 保住自相关,但失败只与失败互换
3. episode 内循环移位 —— 保住边际与自相关,只打乱时刻;**须同时报告该量的 episode 内趋势**,
   因为已测得语法百分位有 85.4% 为正的上升趋势,会使移位对照有偏

**证伪**:若该量在任一有效对照下不优于对照,则不主张检测价值。

## 5. 度量的已知缺陷(必须避开)

- 失败内部的配对报警时刻位移**不是**检测指标:秒表基线已召回 100% 的失败,该指标只测
  "失败之间能否排序",从不测"失败与成功能否分开"。检测侧一律固定成功侧误报后,
  比较失败与成功的报警时刻分布。
- 禁止"每折中位数再取折间平均"。本轮该口径把 −0.55 放大成 −4.80(8.7 倍)。
- 中位数为零时不得只报均值。本轮 91% 的 episode 位移恰为 0,而均值被 9% 的尾部驱动。
