# 256 个 (layer, expert) cell 的共激活结构

纯描述性研究，不构造任何检测器，全程不使用失败标签。`success` 与 `init_state_id < 30` 只用于选取本仓库固定的训练划分。

复现命令：

```bash
python -m moe_grammar.run_cell_coactivation_audit --output-dir results-cell-coactivation
```

产物：`summary.json`（全部数值）、`matrices.npz`（256×256 矩阵、嵌入坐标、模块标签）、`cell_coactivation.png/.pdf`。单次运行 804 秒，纯 CPU。

---

## 结论

**cell 不按 layer 聚成 8 个团。数据自己做出的划分是「前段 L2-L5 / 后段 L12-L15」，而在每一段内部，一个 cell 与其它层 cell 的耦合强度不低于它与同层 cell 的耦合强度。**

四条可量化的支撑：

1. **layer 划分在几何上几乎没有意义。** 在 `1-|r|` 距离上，layer(8) 划分的 silhouette：action `+0.0003`，state `-0.0206`。前者虽然显著高于 cell 标签置换零分布（z=15.5，p<0.001），但绝对值等于零；后者与随机划分无法区分（z=0.1，**p=0.88**）。
2. **front/back 划分强 1 个量级。** silhouette：action `+0.0235`（z=57.9）、state `+0.0334`（z=35.1）；`|r|` 图上的 Newman modularity：action `0.1033` vs layer `0.0423`（2.4 倍），state `0.0556` vs layer `0.0140`（4.0 倍）。全部相对 cell 标签置换零分布，2000 次置换，p<0.001。
3. **数据驱动划分复现 front/back，不复现 layer。** 在 `|r|` 加权图上做 Louvain（40 个种子取共识），action 得到 3 个模块，与 front/back 的 ARI `0.744`、与 layer 的 ARI `0.219`；把分辨率降到 0.8-0.9（modularity 只低 0.007）时直接得到 2 个模块，与 front/back 的 ARI `0.953`。
4. **同层耦合并不比跨层耦合更强。** 扣掉各自的 chance level 后（action）：前段同层 `0.0344` vs 前段跨层 `0.0401`；后段同层 `0.0090` vs 后段跨层 `0.0216`。state 同向：`0.1165` vs `0.1274`、`0.0426` vs `0.0596`。

一个必须写清楚的**反向修正**：后段不是「不耦合」。用后段自己的零分布判定时，L12-L15 之间 6144 对 cell 里有 **1417 对（23.1%）** 在 FDR 1% 下显著。后段是**弱耦合**，不是无耦合；池化阈值下看不到后段边，是因为池化阈值被噪声更大的前段块顶高了。

## 数据与变换

| 项 | 值 |
|---|---|
| run 文件 | 80（40 个 LIBERO-goal 任务 × 2 个 run id） |
| 训练 query | 279,972（`success` 且 `init_state_id < 30`） |
| episode | 18,560 |
| 未做子采样 | stride = 1，用全部训练行 |
| 变换 | 每层内 CLR（centred log-ratio） |

**为什么用 CLR 而不是 sqrt。** 闭合约束是**逐层**成立的（每层 32 个 router 概率和为 1），所以对数比变换要在层内做。载荷严格为正（action 最小 0.0121，state 最小 1.42e-4），不需要零值替换。CLR 保留 cell 身份（ILR 不保留），且尺度不变。

**CLR 的残留约束必须记账。** CLR 强制每层 32 个分量和为零，因此层内非对角相关的均值被钉在约 `-1/31 = -0.0323` 附近。实测：action `-0.0278`、state `-0.0298`。这条约束的方向很关键：

- 在 **正相关图**上，它把层内边压低，layer 划分被**人为不利**（signed 图上 Q(layer) 确实为负：action `-0.0385`、state `-0.0201`）。所以不能用正相关图下结论。
- 在 **|r| 图**上，它把层内边抬高，layer 划分被**人为有利**。本报告的主结论全部建立在 `|r|` 图上，即闭合偏差是站在「layer 划分」那一边的，结论因此是保守的。

额外做了闭合校正（层内 r 加回 `+1/31`）：action 的 Q(layer) 从 `0.0423` 降到 `0.0268`（即表观 layer 结构约 1/3 来自闭合），而 front/back 几乎不变（`0.1033` → `0.0926`）。

**变换稳健性。** 换成 sqrt/Hellinger：非对角元素与 CLR 版本的 Pearson 一致性 action `0.998`、state `0.824`；两者的 8×8 块结构一致（前段块远大于后段块）。state 差异较大是因为它的载荷远离均匀（单个 cell 均值最高 0.30），这一点在「边界」里再说。

**不做的事。** 全程没有计算过任何「a 层 32 维向量 vs b 层 32 维向量」的距离。每一个数字都是两个**单独 cell** 在 query 轴上的相关。

## 零分布：chance level 不是 0，而且逐块不同

三个零分布：

| 编号 | 构造 | 破坏什么 | 保留什么 |
|---|---|---|---|
| N1 | cell 标签置换（2000 次） | 划分与矩阵的对应 | 矩阵本身 |
| N2 | 逐层整体循环平移（200 次） | 跨层对齐 | 层内闭合、层内自相关、任务分块 |
| N3 | 逐 cell 循环平移后重新归一化（40 次） | 全部真实耦合 | 逐层闭合 |

N2 给出的跨层 `|r|` chance level：action `0.0149 ± 0.0005`、state `0.0156 ± 0.0003`。换算成等效独立样本约 **2,857 / 2,627** 条 query（名义样本 279,972）。这是 query 高度序列相关的直接后果，任何把 0 当作 chance level 的读法都会大幅高估显著性。

chance level **逐层对不同**，因为前段 cell 漂移慢、后段 cell 变化快（action：前段块 `0.032`、前后段块 `0.012`、后段块 `0.0050`）。因此下文所有块级比较都减去了**该块自己的** chance level。

N3 与 N2 在跨层块上高度吻合（action 最大偏差 `0.0008`、r=0.9997；state 最大偏差 `0.0060`、r=0.981），说明 N3 是校准过的，可以用它的层内基线做「层内 vs 跨层」比较。

## 嵌入（cell 的 2D 布局）

三种方法，全部基于 `1-|r|` / `|r|`：经典 MDS、Laplacian eigenmaps（spectral）、t-SNE（precomputed，MDS 初始化，perplexity 20）。

| 通道 | MDS vs spectral | MDS vs t-SNE | front/back 线性可分 AUC（MDS / spectral / t-SNE） |
|---|---:|---:|---|
| action | 0.069 | 0.623 | 1.000 / 1.000 / 0.984 |
| state | 0.052 | 0.845 | 0.944 / 0.930 / 0.715 |

（Procrustes disparity，越小越一致。）

MDS 与 spectral 给出几乎相同的布局（Procrustes 差异 0.05-0.07）。t-SNE 作为**布局**不同（非线性方法，Procrustes 本就不适用），但结论一致：三种方法都能用一条直线把前段和后段分开，**没有任何一种方法出现 8 个按层分开的团**（图 c/f/g/h）。

**这里的诚实说明**：kNN-10 邻域保持率只有 0.094-0.318。2D 布局对局部邻域是**不可信**的，只有全局的前/后轴可信。任何从这些散点图里读细节的做法都是过度解读。

## 模块：有几个，是哪些 cell

`|r|` 加权图，Louvain 分辨率按 modularity 最大选取，40 个种子取共识划分。

### action：3 个模块，全部是跨层模块

| 模块 | 大小 | 层构成 | 内部平均 `\|r\|` |
|---|---:|---|---:|
| A | 124 | L12:30, L13:32, L14:31, L15:31 | 0.029 |
| B | 92 | L2:23, L3:21, L4:26, L5:20, + L12.e17, L14.e24 | 0.078 |

模块间：B-C `0.061`，A 与 B/C 均为 `0.028`。种子稳定性（成对 ARI 均值）`0.840`；与 layer 的 ARI `0.219`，与 front/back 的 ARI `0.744`。

- **模块 A 不是真正的模块**，它的内部耦合（0.029）与它到 B/C 的耦合（0.028）几乎相同。它是「低耦合剩余集」：128 个后段 cell 里有 124 个落在这里，离开的 4 个是 `L12.e10, L12.e17, L14.e24, L15.e30`。

- 模块内/模块间的**带符号**平均 r 全部在 `-0.009 ~ +0.001` 之间，即模块是按**耦合幅度**定义的，不是按同向共激活定义的。

### 到底有几个模块

action 的 modularity 在分辨率 1.0 取 `0.1093`（3 个模块），在 0.8-0.9 取 `0.1025`（2 个模块 = front/back，ARI 0.953）。差距只有 `0.007`。因此：

- **稳健的答案是 2 个跨层模块：前段栈（128 个 cell，L2-L5 全部）与后段栈（128 个 cell，L12-L15 全部）。**
- 把前段再切成 B(92)/C(40) 是**试探性**的，它带来的 modularity 提升只有 0.007。

## 对照检验

| 对照 | 做法 | action 跨层 `\|r\|` | state 跨层 `\|r\|` | 块结构 |
|---|---|---:|---:|---|
| 原始 | — | 0.0376 | 0.0941 | 前段块最强 |
| 去任务身份 | 减去每个 run 文件的均值 | 0.0304 | 0.0955 | 不变 |
| 去 episode | 减去每条 episode 的均值 | 0.0316 | 0.0983 | 不变 |
| 去慢漂移 | episode 内一阶差分（261,412 行） | — | — | 不变，前/后比值反而更大 |

**不是任务身份效应**，也不是 episode 相位效应，也不是慢漂移效应。

**方差不能解释前/后差异（仅 action）**：action 的 CLR 标准差前段 `0.033-0.042`、后段 `0.059-0.062`——后段 cell **波动更大而耦合更小**，因此「后段太平坦所以测不出相关」这一解释对 action 不成立。state 反过来（前段 `0.56-0.67`、后段 `0.29-0.33`），这条辩护对 state 不适用。

**矩阵可复现性**：按 episode 随机对半切分，5 次重复，两半矩阵非对角元素的 Pearson 一致性 action `0.9964 ± 0.0003`、state `0.9993 ± 0.0000`（只看跨层元素时为 `0.996` / `0.999`）。

## 边界与可能的伪影

1. **只测线性相关。** 全部结论建立在 CLR 值的 Pearson 相关上。若两个 cell 之间是门控式的非线性关系，本分析看不到。
2. **单一 checkpoint、单一 benchmark。** 40 个 LIBERO-goal 任务 × 2 个 run id。expert 编号本身跨 checkpoint 不可比，因此「模块 C 包含 L4.e13」这类陈述只对这个 checkpoint 有意义。
3. **对半切分的可复现性是乐观的。** 两半共享同样的 40 个任务和 30 个 init state，它衡量的是「重采样 episode 的稳定性」，不是「换任务后是否还成立」。**没有做任务留出检验**，这是本轮最明显的缺口。
4. **前/后强度差与时间尺度共变。** 前段 cell 漂移慢（N2 chance 0.032），后段快（0.0050）。用了两种控制——逐块 chance 扣减、episode 内一阶差分——差距都保留下来（比值 1.9-2.1 倍），但扣减是**加性**的，不能证明前/后差异一定是「耦合」而非「时间尺度」的某种残留表现。
5. **模块数依赖分辨率。** 见上文，2 模块与 3 模块只差 0.007 的 modularity。state 的 5 模块划分种子稳定性仅 0.483，不应引用其成员名单。
6. **稠密加权图上的 modularity 不能用于「观测 vs 代理」比较。** 在 N2 代理图上重跑 Louvain 得到 Q = `0.211`(action) / `0.372`(state)，都**高于**观测值 `0.109` / `0.084`。这是纯噪声图相对权重离散度更大导致的已知假象，`summary.json` 里保留了这组数（`partition_tests.data_driven_shift_null`）并加了 `caveat` 字段，**不可**读成「观测结构弱于噪声」。本报告里有效的检验只有两类：给定划分的标签置换零分布，以及块级 `|r|` 超额量。
7. **层内 vs 跨层的比较依赖 N3。** N3 是合成构造，它的跨层块与独立的 N2 吻合到 0.0008（r=0.9997，action），这是它被校准的证据，但它的**层内**基线没有独立验证途径。
8. **CLR 的层内和为零约束无法完全去除。** 加回 `+1/31` 是一阶近似（假设层内各 cell 方差相当）。真实 layer 结构可能被这一近似低估或高估。
9. **`action_load` 是 10 个去噪步与全部 action token 的平均。** 逐步的相关结构可能不同，本轮没有测。`state_load` 只有单个 token，其 CLR 与 sqrt 的一致性只有 0.824，说明 state 的细节对变换较敏感（front/back 结论不敏感）。
10. **所有 silhouette 都很小（最大 0.0334）。** front/back 是一个很强的**统计**效应，但是一个很弱的**几何**效应：不存在任何清晰可分的团。图上看起来就是一团点，这是真实情况，不是绘图问题。
