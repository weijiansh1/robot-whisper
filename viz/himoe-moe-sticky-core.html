粘滞核心：路由器为什么走不出 trap

机器人卡住的时候，MoE 路由器也卡住了——但不是整体冻结，而是有两三位专家赖在 Top-4 里不走了。

2026-08-27 更正：现象是真的，但它是平凡的

本页展示的粘滞现象确实存在，图和数都没有问题：占用率 0.477 → 0.748， 同一初始状态内 AUC 0.935，13 个 state 里 11 个 above chance。

但它有一个当时没做的对照：机器人卡住 → 观测几乎不变 → 路由器的输入几乎不变 → 选中的专家当然不换。补上这个对照之后——

量结果
占用率 与「路由器输入自身稳定度」的相关r = +0.934
占用率 AUC0.836
把输入稳定度回归掉之后0.419（低于随机，12 个 state 里只 4 个 >0.5）
输入稳定度单独的 AUC0.878（比占用率还高）

所以粘滞不是路由层面的现象，是「输入不动了」的影子。同一批检验还显示路由与隐状态 互为替代（双向配对增量都跨 0），因此也不能说信号坐落在路由上。
