为什么这不是平凡结论

"内部状态能预测失败"本身几乎必然成立——网络当然知道自己在干什么。这个实验有价值， 全在于它排掉了四个平凡解释：

  1. 标签不是从 MoE 来的。 停滞陷入由未来的模拟器物体位姿定义：取成功轨迹终点集合的留出最近邻距离， 若历史最佳距离仍 > 5cm 且未来再也改善不了 1cm，就记为陷入，起点是第一个满足的控制步。 216 条失败里 197 条属于这一类，19 条非同类失败被排除。参照集还剔除了同 initial state 和同 seed 的成功轨迹， 避免用自己预测自己。
  2. 特征严格因果。 评估第 t 步时，所有预测量只用 ≤ t 的数据，历史窗 7。没有任何一个特征读到未来。
  3. 比较发生在同一个初始状态内部。 512 条 = 16 个 initial state × 32 个 flow-noise seed。 同一个 state 里 32 条的物理初始条件完全相同，只有去噪噪声不同。AUC 只在同一 state 内部配对正负样本再加权合并， 所以"某些场景本来就难"这个混淆被结构性地消掉了。
  4. 泛化同时留出场景和种子。 4×4 双重留出：训练折与测试折既不共享 initial state，也不共享 noise seed（16 折，每条样本恰好被测一次）。 每个特征块只用训练折做标准化 + 白化 PCA-12，读出器是固定的 ridge。

在这个骨架上，"MoE 组"和"物理组"是唯一的变量：同样的标签、同样的折、同样的降维容量、同样的读出器， 只换喂进去的特征块。所以两条曲线之间的差就是"表征里有什么"的差。

边界一：陷入之前什么都没有

同一批 32 条 state-42 rollout 上累计跑过 359 个确认检验，各报告实际施加的最大 Bonferroni 是 36。 按 359 校正后只有 11 个存活，全部在 t34。

边界二：t27 / t34 在陷入之后，是"读出"不是"预测"

197 条停滞陷入的行为学起点分布；竖线是五个评估时刻。
