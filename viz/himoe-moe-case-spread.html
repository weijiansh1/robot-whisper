逐个 case 看：MoE 增量在 13 个初始状态上的分布

一、13 个初始状态各自的增量曲线

线的粗细与不透明度代表该 state 的正负样本对数——细而淡的线是小样本，噪声大。粗黑线是 pairs 加权均值。

极端值全部来自小样本：。7 个 pairs ≥ 100 的 state 在 t34 上 6/7 为正。

二、漏斗图：噪声从哪来

横轴是该 state 的正负样本对数，纵轴是 t34 增量。样本越少，散得越开——典型漏斗形。

三、留一验证：没有哪个 state 在独扛

每次剔掉一个 initial state 重算 t20–t34 合并增量。13 次结果全为正，且范围很窄。

四、为什么没做跨任务验证

每个任务里失败都跑满步数上限、成功早早结束，所以「全员存活」的共同队列在另外三个任务上只到 t8–t16——早于效应出现的窗口。硬做就得砍掉早结束的成功轨迹，直接回到幸存者偏差。
