# HiMoE 路由与真实专家贡献的 SVD 验证

## 口径

- SVD 本身不读取动作、reward、仿真状态或 success。
- 真实激活使用 top-k 专家加权向量合并后的 routed vector；四层先按各层 RMS 等尺度化，再去掉每个 denoise round 的公共均值。
- 路由使用逐 site L1 归一化概率的平方根，因此欧氏距离对应 Hellinger 几何。
- success 只在分解完成后作探索诊断，并另做 scene-held-out 复核。

## 真实 routed 向量

数据：512 个首 query，16 scene x 32 noise，10 轮 x 4 层 x 1024 维。

| 数据处理 | PC1 | PC1-4 | PC1-16 | PC1-64 | stable rank |
|---|---:|---:|---:|---:|---:|
| 原始向量、全局中心化 | 30.1% | 47.7% | 65.8% | 84.6% | 3.32 |
| 层等尺度、去 round 模板 | 12.1% | 27.1% | 50.2% | 76.8% | 8.25 |

去 round 模板后 PC1-16 仍解释 50.2%，说明真实专家贡献不是纯一维幅度；但前 32 个方向中 scene/noise 主效应分别解释加权 48.8% / 20.1%。

前 16 维当前轮到最终轮的 CKA 为：`0.562 0.602 0.633 0.670 0.715 0.781 0.841 0.899 0.946 1.000`。去掉 scene+noise 主效应后为：`0.030 0.040 0.059 0.059 0.093 0.105 0.106 0.114 0.159 1.000`。

这意味着早轮和最终轮看似很一致，但大部分一致性来自固定 scene/noise 身份；真正 query 特异的未来贡献在第 9 轮前仍很弱。
scene 对半后，激活 top-4 / top-16 子空间的平均 principal cosine 仅为 `0.455 / 0.566`，说明深层残差方向本身也不够稳定。

## 与最终成功的诊断

全样本事后扫描 320 个 PC x round，最大相关为 `r=-0.178`（round 5, PC10），max-statistic FWER `p=0.0360`。

但冻结到另一半 scene 后，两次方向的相关分别为 `0.025`、`-0.020`，单侧 p 为 `0.342`、`0.642`。因此这个成功相关没有复制，不能当作 outcome signal。

## 30 任务完整控制步路由

数据：18384 个 control query、1500 条 rollout、30 个任务。

全局路由 PC1/PC1-16/PC1-64 分别解释 4.9% / 31.5% / 61.6%，stable rank 20.23。
前 32 维的 task / phase 加权解释量为 19.7% / 5.1%；PC1 的 task eta 是 0.832。主方向首先编码 checkpoint/任务身份，不是通用阶段。
task 对半后，top-4 子空间平均 principal cosine 为 `0.887`，比单任务激活残差稳定得多。

不过，用训练任务的前后 query 顺序无监督地确定一个 SVD 时间箭头后，两个 15-task holdout 的 episode 中位 Spearman 为 `0.659 / 0.818`；正相关 episode 为 `740/750` 和 `747/750`，两边都是 15/15 任务同号。

这是一个可重复的模型内部控制进度轴，但它只表示 query 序列的先后，不证明物理任务更接近完成。

## 对早停的含义

不去 round 模板时，纯序列顺序构造的 denoise SVD 轴在两半未见任务上的 query 内 rho 中位数为 `1.000 / 1.000`；去掉 round 模板后降为 `0.394 / 0.442`。
去模板后平均 rho 只有 `0.150 / 0.148`，正向 query 为 `5563/9491` 和 `5309/8893`，远不如公共时钟稳定。

所以 denoise SVD 很容易读出‘现在是第几轮’，但去掉公共时钟后没有稳定的 query 特异收敛轴。
此外，query SVD 的 PC1-16 只保留 20.3% 的相邻路由变化能量，PC1-64 保留 53.3%；高维尾部仍承载接近一半动态变化。直接按低维变化小来早停会漏掉这些变化。

## 裁决

- **可解释性：有结果。** SVD 提取出了跨 30 个任务复现的内部控制进度轴，可用于无监督阶段分段、变化点检测和 OOD/阶段原型研究。
- **成功预测：没有通过。** 全样本弱相关在 scene-held-out 后归零。
- **逐次推理早停：暂不通过。** 去 round 模板后没有稳定收敛轴，且低秩截断会漏掉大量动态能量。
- 下一步应把这个进度轴用于跨 rollout 阶段对齐；早停仍优先验证联合采集中的真实激活残差 + controller-aware endpoint，而不是单独用 SVD 分数。
