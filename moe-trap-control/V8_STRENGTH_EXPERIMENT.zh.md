# V8 控制幅度与持续时间实验

2026-09-08，384 条完整后缀、全量审计和原服务健康检查均已完成。

当前干预在首次冻结 v8 报警 q 的下一次查询前开始。主轨迹保持原样，完成后通过完整 C0 重放取得可恢复状态。每个受控查询先用相同观测、相同噪声做原生 shadow，按照前后层路径比例、三点曲率和跨查询移动量构造偏置，然后执行 `softmax(logits + multiplier * bias)`，实际重新选择 Top-4 和混合权重。只直接改变 HB 后四层 12/13/14/15 的动作 token，不采集 hidden。

原单位偏置每个位置的 RMS 上限为 0.35、绝对值上限为 1。本轮在原限幅完成之后乘 1、4、16，不重新截回原上限；因此 16 倍表示 gate 偏置扩大 16 倍，不表示动作扩大 16 倍。持续时间分别为最多 5、20 次查询，即最多 50、200 个环境动作，之后撤销控制；成功或原有 520 步预算耗尽即停止。

## 样本与结果

从前轮 42 个已审计报警状态中，按 benchmark、报警来源和原始成败分层，以固定哈希轮转选出 24 个：Pro 13、Plus 11，原始失败 22、成功 2。保留成功对照；选择不使用本轮干预结果。每状态两次配对重复、8 组，共 384 条后缀；新增主轨迹覆盖为 0。

主分析排除 1 个未改变场景的失败对照，剩余 23 个状态，21 失败、2 成功。因此每组有 42 次失败轨迹尝试和 4 次成功轨迹尝试。

| 方法 | 持续查询上限 | 救回 / 原失败尝试 | 误伤 / 原成功尝试 |
| --- | ---: | ---: | ---: |
| 组合 1 倍 | 5 | 0 / 42 | 0 / 4 |
| 组合 4 倍 | 5 | 0 / 42 | 0 / 4 |
| 组合 16 倍 | 5 | 0 / 42 | 0 / 4 |
| 组合 1 倍 | 20 | 0 / 42 | 0 / 4 |
| 组合 4 倍 | 20 | 0 / 42 | 0 / 4 |
| 组合 16 倍 | 20 | 0 / 42 | 0 / 4 |
| 随机方向 4 倍 | 20 | 0 / 42 | 0 / 4 |
| 随机方向 16 倍 | 20 | 0 / 42 | 0 / 4 |

纳入场景对照后每组仍为 0/44 救回，覆盖 22 个不同失败状态。主分析 Pro 每组 0/22，Plus 每组 0/20。所有方法相对历史配对 native、相对本轮复现的原强度，均为 0 赢、0 输。随机方向是专家维置换的组合偏置，第一查询保持相同状态和幅度，分叉后各自在当前观测上计算。

## 干预传递到了哪里

以下先对每条分支前 5 次受控查询取均值，再跨主分析分支取中位数。相同幅度的 5/20 查询组在前 5 次查询逐字段一致，因此这里只列一份。

| 幅度 | 实测偏置 RMS | 最大专家混合权重 | Top-4 集合改变占比 | 连续 6 维动作 RMS 差 | 前后层 log 比变化 | 曲率 / shadow | 移动量 / shadow |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 倍 | 0.1951 | 0.2814 | 99.10% | 0.00136 | +0.1738 | 0.576 | 3.546 |
| 4 倍 | 0.7807 | 0.3708 | 99.95% | 0.00190 | -1.3406 | 0.940 | 11.022 |
| 16 倍 | 3.1223 | 0.6425 | 100.00% | 0.00253 | -2.4790 | 5.255 | 28.533 |

16 倍偏置将连续动作差扩大到约 1.86 倍，远非 16 倍。动作坐标是模型输出坐标，不能直接换算成米；夹爪单独统计，以上连续 RMS 不含夹爪。

过大的组合偏置还改变了目标方向：1 倍时全部 46 条主分析分支的三个目标方向同时改善；4 倍时前后层比例均恶化；16 倍时前后层比例和三点曲率均恶化。此处是前 5 次受控查询的分支均值，不是报警重校准。这表明放大近似局部控制方向不能保证继续改善这些特征。

这些结果支持将“风险检测”和“恢复收益”分开研究。当前这组 gate 偏置未产生恢复收益，不能据此断言所有 MoE 控制均无效。下一轮应固定一个可测量的恢复模块，单独比较触发时机，并保留无报警轨迹、成功轨迹和同耗时对照。

## 验证与资源

- 6 项控制范围、实际幅度、原 hook 等价性、清理和 BF16 数值重构测试通过。
- 48 条原强度后缀与前轮完整后缀逐字段一致；144 对持续时间比较的前 5 次查询一致。
- 384 条完整后缀全量审计通过，包含原 C0 承诺、快照、实际状态链、种子、动作预算、路由及计数。
- 保存了真实加法前后 logits、舍入后的偏置和数据类型，独立复算 BF16 最近偶数舍入与 FP64 softmax，并核对实际执行的 Top-4 / 权重。没有保存 hidden。
- 采样前向 12,777 次，启动检查 88 次、结束健康检查 20 次，合计 12,885 次请求前向；本轮复用了此前完成的 C0，其成本没有重复计作新采样。
- 采样 585.85 秒，即 9.76 分钟，平均 21.81 次前向/秒；采样目录约 2.23 GiB。
- 物理 GPU 0–3，每卡 8 个独立 batch=1 副本，私有 MPS。全程平均利用率分别为 93.2%、84.9%、87.1%、93.0%；各卡同时有 8 个活跃任务时为 97.3%、95.9%、95.0%、97.2%。峰值功率 278.6、308.6、307.7、270.7 W，不将峰值描述为持续功率。
- 全部临时进程和私有 MPS 已退出。原 PID 28531 保持运行，0–3 卡 20 个原端点均通过真实推理检查；未使用 GPU6。
- 运行摘要的 `completed_jobs` 是末次遥测时的 47；最终任务数组为 48/48 completed，审计核对了全部 48 个任务及 384 条后缀。最终计数以任务记录和审计为准。

本轮是报警条件下的探索性实验，重复不是独立主轨迹；两个成功状态不足以证明普遍无害。所有配对差为零时，bootstrap 区间记为空，不用退化的 `[0,0]` 声称等效。
