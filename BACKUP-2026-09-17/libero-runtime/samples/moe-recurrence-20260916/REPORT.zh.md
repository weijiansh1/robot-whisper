# MoE 轨迹的复返定量分析：拓扑/复返到底有没有信息

日期：2026-09-16。起因：拓扑定义网格实验的结论"复返区域特征无结局信息"（0/25,740 组六尺度一致，置换 P=0.60）过强。
本轮用更公平的方式重新检验，不新增模型前向和环境动作。

## 网格实验的判据为什么对拓扑不公平

- 复返区域特征要先积累 8–16 个 query 的参考再观察 8 个 query，q12–q16 时多数 episode 尚未进入 trap。
- 六个半径尺度中通常有 3–4 个退化（未建立区域，AUROC 恰为 0.5），"六尺度同向"不可能满足。按"非退化尺度内同向"重判
  （`regrade_region_scales.py`，锚点 ≤ q24）：全体 23 组、LIBERO-10 38 组、Plus 186 组在 ≥3 个非退化尺度上一致且 |task AUROC| ≥ 0.65，
  最好的约 0.70–0.81（`outside_fraction`，state_back / shared|back_last，q20–q24）。Plus 的多数"1.0"是每任务只有 1–2 个成功样本的假象。
- 置换检验比的是两万多组里的最大值，家族越大越难过；区域特征本身接近二值，AUROC 受平局限制。
- 复返特征还要看锚点之后 8 个 query，不是锚点处的因果特征；simple/persistence 才是因果的。

## 本轮方法

- 数据：网格已存的 170 集 × 60 个因果距离矩阵（路由 Hellinger；MoE input/shared/total/input_total 端口 RMS；按 back_path / full_path / back_last / state_back / 8 层切片），
  trace 里的末端位置与夹爪，v8.2 逐 query 轨迹，以及去噪路径弯曲度 L/D。
- 因果窗口 W = 14 个 query，Theiler 窗口 3，ε = 全体 episode 前 14 个 query 间距离的 10% 分位（global）；另做 episode 自身因果前缀分位（prefix）。
  RR 复返率；RET 真复返（先离开 2ε 球再回到 ε 内，即"走了一圈回来"）；LAM 层流率（相邻步 ≤ ε，原地不动）；LMAX 最长对角线（重复子轨迹）；DIAM 窗口直径（幅度基线）。
- 物理标签：停滞块 = 10 步内末端位移 < 5 mm 且夹爪不变；往返循环事件 = 回到 12 个 query 内某点 1 cm 内且中途离开过 ≥ 2.5 cm（夹爪状态相同）。
- 统一报告 60 个矩阵的中位数与最好值，避免只报挑出来的设置。

## 判断

1. 收回"复返/拓扑没有信息"。有信息的是**复返率、层流率、最长对角线**这类"MoE 状态不断回到同一个小邻域"的度量：60 种表示的中位数在 q16–q24 就有 0.72–0.79，12 组阈值设置全部同向，两个基准一致，高于 v8.2 freeze（0.64–0.77）。
2. 这种信息的一部分是"动得少"，但不全是：按直径分层后仍有 0.63–0.69；对物理上仍在移动的失败集，复返率与直径同样能把它们和成功集分开（≈0.72），而 v8.2 freeze 只有 0.57–0.58。图 (b) 是典型：机器人只有 6% 的块停滞，MoE 状态却从 q≈22 起整块复返——身体在动，决策在原地打转。
3. 没有信息的是"真循环"：MoE 空间里先离开再回来的 RET 在任何设置下都接近 0.5，物理往返循环本身也极少（5 集）。trap 的几何是"塌缩到一个紧致的复返区"，不是环。P3i 的持久同调 H1 结果与此一致。
4. 对结局预测而言，复返在直径之上的增益很小（+0.00 到 +0.03），所以它的价值在解释和"移动型失败"这一类，不在替换现有幅度特征。

## 局限

同一批 170 集，未做留出；60 种表示 × 4 个度量的中位数是保守汇报，最好值仍有选择偏差；q24 之后成功样本迅速减少（q32 仅 5 个）；
物理标签只用末端位置和夹爪；Plus 的类别成功率差异大（Camera 1/10），LIBERO-10 侧数字更干净；ε 取全体早期窗口分位，跨模型部署需重新标定。
