# 去噪路径弯曲与物理停滞 / 跳出的关系

日期：2026-09-16。问题：陷入 trap 时，去噪路径不再是直线，是否意味着最终会跳出 trap？

## 数据

- 今天拓扑实验的 170 集本地轨迹（`simulations/topo-libero10` 100 集 61 成功，`simulations/topo-plus` 70 集 25 成功），共 6,560 次 query。
- 每个 query 用独立模型实例重放（固定 flow noise），记录 10 步 Euler 的 `x_t`，重放动作与 trace 全部逐位一致（max |diff| = 0）。
  9 个 worker 分布在 GPU 0–7，新增环境动作 0，共享服务未动。
- 弯曲度：真实 7 维 × 10 token 展平后的路径长度 / 弦长（L/D）；辅以首末速度夹角、偏离弦线的最大垂距、一步外推终点误差。
- 物理标签：trace 里每个 query 边界的末端位置和夹爪开度。"停滞块" = 10 步内末端位移 < 5 mm 且夹爪开度变化 < 0.005；"运动块" = 位移 ≥ 10 mm 或夹爪变化 ≥ 0.01。
  停滞段 = 连续 ≥ 2 个停滞块；"恢复运动" = 段后出现非停滞块；"持续到失败" = 段一直延续到 520 步上限。
- v8.2 逐 query 的报警和 freeze 分数来自 `moe-capture/topo-20260916/_grid/episodes/<tag>.npz`。

## 结果

| 检验 | 数值 |
| --- | --- |
| 停滞块 vs 运动块的 L/D（AUROC，停滞更弯） | 0.76；分时间段 0.78 / 0.71 / 0.61；中位 1.0091 vs 1.0037 |
| 停滞段末两块的 L/D：恢复运动（110 段）vs 持续到失败（36 段） | AUROC 0.52 [0.42, 0.63]；段内趋势 0.39（持续失败的段反而略升） |
| 更严的跳出定义：恢复且持续 ≥ 2 块运动（73 段） | 0.56 [0.45, 0.66] |
| 恢复运动且最终成功（仅 5 段） | 0.51 [0.22, 0.82]；按 episode z-score 后 0.86 [0.66, 1.00]，样本过少 |
| 停滞块的 L/D → 下一块是否运动（165 动 / 1,075 不动） | 0.61 [0.54, 0.68]；分时间段 0.67 / 0.71 / 0.57 |
| 停滞块的 L/D 与下一块位移的偏相关（控制 query 序号） | −0.07 |
| 停滞块内 L/D 与"指令动作相对上一 query 的变化"的 Spearman | +0.36 |
| L/D 与 v8.2 freeze 分数的 Spearman（全部 query） | +0.32 |
| 首次 v8.2 报警后 5 个 query 的 L/D：成功（4 集）vs 失败（69 集） | 成功更低，AUROC 0.29（p = 0.17） |
| 整集中位 L/D：失败（84）vs 成功（86） | 1.0065 vs 1.0030，AUROC 0.975（非因果前缀，受集长混杂） |
| 固定锚点 q16–q20 的因果前缀结局 AUROC（pooled，84 失败 / 80 成功） | 近 5 query 平均 L/D 0.68–0.73；一步外推误差 0.71–0.77；v8.2 freeze 0.63–0.66；v8.2 报警 0.53–0.57 |

分基准：近 5 query 平均 L/D 在 LIBERO-10 为 0.69–0.76，Plus 为 0.68–0.77；一步外推误差在 Plus 为 0.73–0.81。
图中 (a) 显示恢复运动的段在恢复后的第一、二块 L/D 升到 1.018，而段末停滞块两组几乎相同（1.0145 vs 1.0155）。

## 判断

1. 弯曲是"卡住"的标记：停滞块明显比运动块弯，失败集整体比成功集弯，且与 v8.2 freeze 分数正相关。
2. 弯曲不是"跳出"的先兆：停滞段结束前的弯曲度在"恢复运动"与"持续到失败"两组间没有差别（0.52），
   控制时间后弯曲度与下一块位移无关（−0.07）。弯曲度升高发生在动作真正改变的那一块（恢复后 L/D 1.018），
   与"指令动作在变"同时出现（+0.36），是同步现象而不是预测信号。
3. 停滞块更弯时下一块略更可能出现运动（0.61），但这种运动很少通向成功：110 个恢复运动的停滞段只有 5 个属于最终成功的 episode。
4. 作为早期信号，固定锚点上的弯曲度对最终结局的 AUROC 高于 v8.2（0.68–0.77 对 0.53–0.66），量级接近今天拓扑网格里的 MoE 运动幅度特征（0.74–0.80），
   且不需要额外前向。这是在同一批 170 集上从 7 个特征 × 5 个锚点里挑出的描述性数字，未做留出验证、阈值标定和跨基准迁移。

## 局限

停滞只用末端位移和夹爪定义，不是任务谓词层面的 trap 真值；弯曲度只来自实际执行的那一个噪声样本；
弯曲度随 query 序号上升（Spearman 0.47），整集比较受集长混杂；"跳出后成功"样本极少（5 段），无法检验。
