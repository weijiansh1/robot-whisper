# P3i：仅失败样本的 MoE 复返与拓扑诊断

2026-09-15。用户要求利用拓扑思路进行分析与实验。本轮先在已封存数据上检验诊断假设，不新增模型前向、环境动作或成功父轨迹，不修改模型、共享服务、v8.2 或旧产物。

## 样本与问题

使用 P3h 的全部六个原失败父状态、四组未来噪声、两臂，共 48 条完整续跑。原配对成功率已经知道，均为零；本轮不是新的恢复率试验。P3f 只使用与这些失败父轨迹相交的四个父状态、各三个定点，共十二组条件交叉对照，不读取原成功父状态的张量。

H1：当前短时重规划是否只是留在或返回同一个可观测 MoE 复返区域？与同噪声原策略对照，不把原策略本来就会离开视为干预收益。

H2：延迟嵌入后的路由点云是否包含超出打乱对照的环状结构？持久同调中的 persistence 指几何尺度，不是物理时间持续长度；有环不是失败标签，没有环也不能排除冻结。

H3：纯路由的邻域与连通分量是否会区分计算完全相同的干预？这是一项构造性负对照，不是证明 MoE 输出能够充分描述完整系统。

## 冻结表示与时间

每个点对应一次完整推理，不把十个内部 flow 轮数当作十次物理交互。只在绝对物理十步网格读取 P3h；window5 的五步中间查询不进入此分析。每条完整记录有查询 0--51，最后一个路由点对应第 510 步，不伪造第 520 步路由。

主表示为 L12--15、全部十个 flow 轮数、十个动作 token 的 32 专家概率。每个专家分布先归一化，再取平方根；各层/flow/token 等权，距离为均方 Hellinger 距离的平方根。不是仅比较 top-k ID。

同时固定两个敏感性表示：全部八个 HB 层的完整 flow；后四层最后一个 flow。三种表示各使用 epsilon 倍数 0.75、1、1.25，共九个设置，全部报告，不择优。

状态使用当前与前两次查询的三个点组成延迟历史；距离是三段距离平方均值的平方根。无需全数据 PCA、任务标签或未来结果拟合。

## 因果参考区域

每个配对只用介入前历史及首个共同提案定义参考区域：最近十二个延迟状态，以分叉 query 为末点。最早 q13 有足够历史。首个共同提案是执行前可读信息，两臂必须逐值一致。

epsilon 基值为每个参考点到时间间隔至少三次查询的其他参考点之最近距离的 95% 分位数，数值下限 1e-12。用 complete-link 层次聚类形成粗状态，避免单链接把长路径直接串成一个区域。

只沿真实相邻查询建立有向边，用 SciPy 强连通分量得到候选区域；选择包含当前末点的分量。候选须被访问至少四次、跨至少三次查询、有循环或自环，并且区域内首尾距离 / 累计路径长度不超过 0.35。最后一项是固定的漂移排除启发式，不是拓扑定理或已验证阈值。

条件不满足就标记“参考复返区域未建立”，不强制解释成 trap。参考点、半径和图在介入时固定，不向未来扩充。

新状态到该区域任一参考点的距离不超过 epsilon，视为在观察邻域内。三次连续网格观测在外才确认离开，跨二十个物理步；两次连续在内确认观察到返回，跨十步。末尾至少四次在外才能标记“末次离开后未观察到返回”，末尾覆盖三十步；这只是截至第 510 步的有限观察，不是永久逃离。

互斥类别：未确认离开、离开后返回、末次离开后未观察到返回、随访不足或混合、参考区域未建立。另报告所有离开/返回事件、区域占用和九设置一致性。离开后仍失败不自动意味着陷入另一个真实 trap。

## 拓扑与负对照

主表示的后缀点列单独做三点延迟嵌入，使用 GUDHI 3.13.0 的完整 Vietoris--Rips 二维骨架计算 H0/H1，系数域为 2。报告最大 H1 寿命及其除以点云直径的值；零直径记零，不做逐窗口方差归一化以免放大冻结噪声。

每分支 99 次全打乱与 99 次长度三的分块打乱，保持点数、边际状态及各臂配对随机顺序，重新做延迟嵌入。输出原始经验尾部比例，仅作开发数据的描述性比较，不宣布未校正显著性、报警精确率或召回率。无延迟点云在重排下同调不变，作为实现对照。

合成对照固定：静止、周期、单向漂移、离开再返回、持续离开以及相同点云时间打乱。合成阳性指几何/复返现象阳性，不是使用成功机器人轨迹。先通过实现测试，再分析真实记录。

P3f 每个固定输入的 native、joint、route_only、output_only 分别比较实际 effective 路由与 MoE input+total 表示。只构建同一输入下四个候选的局部邻域，不把三个不连续 phase 或十个 flow 拼成真实时间轨迹。检查计算匹配对在全部已保存 HB input/total 与动作上逐元素一致，再比较四点距离和有限 H0 合并尺度；零距离等价类按数值零检查，正距离的差别不自动构成控制语义差别。

## 继续边界

P3h 没有连续有效 MoE 输入/输出，本轮不能验证真实续跑在计算表示上的复返结构；不从路由推测缺失输出。只有十二个定点反事实对照，不能把它们当成十二段闭环轨迹。

九设置不稳定、参考区域不足，或路由与等效计算不一致时，不把该路由指标提升为自动控制器的成功判据。即使分析稳定，也只提出下一轮候选假设；已有全失败数据不能学出通向成功的方向。本轮不在结果之后自动增加窗口、改变阈值或启动新仿真。

配置、规则、源码、库版本与输入哈希在真实分析前冻结；结果另建 P3i 目录。完成独立复算、合成测试、图表检查与旧文件完整性检查后封存。

## 依据

- [Sliding Windows and Persistence](https://arxiv.org/abs/1307.6188)：延迟嵌入与持久同调可用于周期性分析，不提供任务失败或因果恢复判据。
- [Conley Index for Multivalued Maps](https://link.springer.com/article/10.1007/s10208-024-09685-4)：复返区域与转移的理论启发；本轮有噪有限采样图不具备严格 Conley 指数认证。
- [SciPy connected_components](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.csgraph.connected_components.html)：使用现成强连通分量实现。
- GUDHI 3.13.0：使用独立安装包中的 RipsComplex / SimplexTree API 与文档；官网文档访问超时已知，安装包 API 另行核验，不自行编写同调算法。
