# P2a：候选动作覆盖结果

本轮是动作空间预检，不是物理续跑或恢复率测试。

- 8 条 init39 父轨迹，Plus / Pro，基础任务 0/3/6/9，固定 q8；与前两轮父轨迹不重叠。
- 正式实验 384 次独立前向 + 9 次原服务对照；采集后追加 1 次原候选重放用于 logits 审计，总计 394 次模型前向，环境动作 0。
- 每方法每池四个新候选，加共同默认动作；两个随机池，八个独立噪声参考动作。

## 父轨迹等权结果

动作 RMS 使用 checkpoint 前六维 action std 标准化；覆盖增益是到参考动作的最近距离相对默认减少的比例。

| 方法 | 平均动作 RMS | 候选两两 RMS | 参与率维数 | 参考覆盖增益 | 优于噪声的父轨迹 |
|---|---:|---:|---:|---:|---:|
| IID 噪声 | 0.085194 | 0.084331 | 2.075 | 17.83% | 0/8 |
| 状态 gate 0.10 | 0.003291 | 0.003524 | 2.261 | 0.61% | 0/8 |
| 动作 gate 0.10 | 0.004871 | 0.004982 | 2.356 | 0.88% | 0/8 |
| 动作 gate 等 L2 | 0.003455 | 0.003628 | 2.557 | 0.59% | 0/8 |
| 固定 2 噪声 + 2 状态 gate | 0.045855 | 0.062763 | 1.532 | 13.96% | 0/8 |

预定主方法为状态 gate，其参考覆盖增益相对 IID 噪声差 -17.22 个百分点。其他方法属于预定次要对照，不事后替换主方法。

## 解读边界

参考分布来自独立 IID 噪声，衡量的是对该策略动作区域的几何覆盖，不是正确动作或恢复标签。默认动作在每池中，所以覆盖增益非负也不表示物理上无害。
状态 gate 与动作 gate 等 L2 组匹配总偏置；动作 gate 0.10 组只匹配单位置幅度，其总偏置 L2 为状态组的 sqrt(10) 倍。
固定混合池始终取两种方法的前两个候选，没有按动作或参考挑选。离线最近邻是评估指标，不是已经可部署的 MoE 选择器。
两个池和八参考均先在父轨迹内平均；只有八父轨迹、四基础任务，不宣称统计显著性。32 次规定重复完全一致，不代表所有候选均重复。
P2 物理 C0、报警触发与完整后缀尚未执行。原 P2 恢复门槛不能由本报告替代，P3/P4 没有启动。

## 审计与资源

裸推理、native、零偏置、重复、清理后输出与规定对照一致。修订后的独立审计通过：384 条独立响应、9 条共享响应、80 个候选池、256 个不同候选、64 个参考动作及 32 次规定重复全部核对，覆盖指标从原始数组独立复算一致。
PyTorch 峰值分配 15732.1 MiB，缓存 15924.0 MiB；原 9500 未修改或重启。

详见 `analysis.json`、`states/`、`coverage.png`、`independent-audit.json` 和 `verification.json`。

独立审计的首次摘要检查暴露了重建端未保留未干预位置负零符号的问题，原始字节摘要与采集日志全部吻合。恢复 `+0.0` / `-0.0` 后，第二次审计又暴露了把 FP32 softmax 概率当作 FP32 logit 加法的错误假设。两次失败实现保留，没有改变正式数据、非零偏置或覆盖指标。

追加的真实模型重放记录了 80 个 gate 调用的 logits：logits / bias 加法为 BF16，softmax 概率为 FP32。该请求的动作和完整路由与原候选完全一致；请求 +0.10 时实际正 logit 增量包括 0.09375、0.09765625、0.1015625 等，最大偏离约 0.00625。CPU 按真实 dtype 重建加法完全一致，保存 logits 的 softmax 复算最大差约 `2.98e-8`；采集时 GPU softmax 核对完全一致。

审计 v2 使用真实 logits 验证舍入，不将不适用的 `native_probs * exp(requested_bias)` 公式用作正确性门槛。正式 376 条全捕获响应的实际专家、归一化权重、作用范围及 wire 核对仍全部通过。修正记录见 `audit-correction.json`，最终审计版本和哈希见 `independent-audit.json`，追加前向见 `logit-diagnostic/`。

正式采集耗时约 499 秒；追加诊断含加载约 94 秒。上述精度证据只验证了一个重放请求，尚未量化 BF16 舍入对候选覆盖差或跨幅度非线性的贡献。
