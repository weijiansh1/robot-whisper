# P3f: MoE 路由与输出交叉对照

## 范围与冻结设计

只研究 MoE 内部计算，不启动环境，不读取模拟器状态，不执行动作，不用任务成功标签选择候选。保留策略原有图像、机器人观测和提示输入。权重不训练、不修改，所有干预都是请求级 hook。

固定复用 P3e 的 15 个开发状态: 5 条父轨迹各取 before_alarm、first_accepted、last_accepted。后两类状态此前已经按候选通过筛选选出，不能当作独立留出集。沿用该状态原始历史前缀、噪声和 mobility_balance 偏置，不重新搜索强度或方向。

每个状态按以下顺序调用 9 次，总计 135 次实际前向、60 个主对照观测、75 个验证观测。验证观测不是独立样本。

| 调用 | 门控规则 | HB 合成输出 | 用途 |
| --- | --- | --- | --- |
| native | 原生 R0 | 自然 O0 | 原生基线、O0 供体 |
| joint | 原偏置 R1 | 自然 O1 | 正常路由干预、O1 供体 |
| native_replay | R0 | 回填 O0 | 原样回填控制 |
| joint_replay | R1 | 回填 O1 | 原样回填控制 |
| route_only | R1 | 回填 O0 | 改路由、隔离输出影响 |
| output_only | R0 | 回填 O1 | 不加偏置、传递候选计算结果 |
| repeat_route | R1 | 回填 O0 | route_only 重复 |
| repeat_output | R0 | 回填 O1 | output_only 重复 |
| post | R0 | 自然计算 | 撤销后检查 |

## 干预语义

R0 是不加偏置的原门控函数，不是强制使用原生轨迹上的全部专家 ID。输出回填改变下游隐藏态后，原门控可自然响应。output_only 的路由应该与 joint 在同一隐藏态上的偏置前路由比较，同时另行报告它相对 native 轨迹的变化。

门控偏置固定作用于 HB 第 12、13、14、15 层，10 个去噪步，动作 token 1:11，最大绝对值不超过 0.30。输出回填严格覆盖同一范围。回填张量是 routed + shared 的完整 MoE 输出、尚未加 residual，不直接回填 state token、前四个 HB、block 输出、速度或动作。

O0/O1 来自当前状态的前两次真实前向，不能跨观察或跨噪声复用。先记录原始 MoE 输出，再回填，再采集实际传递输出与后续计算。保存两种输出、完整 HB 原生/有效路由、HB 输入/共享输出/残差/block、动作投影输入、速度和动作。

## 预注册检查与分析

1. 新 native/joint 与 P3e native/combo 的路由、激活和动作逐元素一致。
2. 两个原样回填、两个重复及 post 与各自供体或前次调用逐元素一致；所有 hook 请求结束后移除。
3. route_only 的有效计算链和动作与 native 一致，但路由可变。output_only 的有效计算链和动作与 joint 一致，但其门控未加偏置。此计算匹配是实验构造，不是独立发现。
4. 回填范围外 raw total 与 effective total 精确相等；范围内等于对应供体；residual + effective total 精确重建 block。
5. 独立重算门控 BF16 加法、FP32 softmax、top-4 分派和五个 v8.2 分数。各组使用同一实际历史前缀，不推进或重置历史。
6. 报告瞬时分数变化、正式平滑分数及阈值、top-4 变化率、原始/有效输出差、归一化动作差。既有瞬时候选筛选只作诊断，不控制本轮执行。
7. 分析单位为 15 个配对状态、5 个父轨迹，不将 135 次调用当成独立样本，不推算任务精确率、召回率或救回率。
8. 核对参数内容哈希及版本、已有 8 轮封存文件与源码、共享 9500 服务身份。隔离加载，显存分配限制 16 GiB，不向共享服务发推理请求。

解释重点: 同一有效计算是否可以伴随不同的路由指标，以及指标通过是否足以代表计算改变。不能由构造出的动作相等推断路由无用，也不能把门控函数保持原生写成全部路由 ID 保持原生。
