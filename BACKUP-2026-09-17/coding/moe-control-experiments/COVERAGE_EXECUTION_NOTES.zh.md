# P2a 执行说明

用户在 P1b 后询问“不稳定”的含义并要求继续实验。本轮使用离散候选池，不假定 gate 幅度与动作变化具有稳定的线性关系；P1b 已验证的重复一致性不变。

正式目录：`runs/p2a-coverage-20260914-4i18r353`。北京时间 2026-09-15 启动，目录日期使用 UTC。该文件是进度与解释记录，不属于被冻结的采集实现。

## 冻结前检查

- 21 项协议/运行适配单元测试通过。
- 另用独立实现复算合成覆盖指标及 32 种候选、8 种参考输入配置，结果一致。
- 中心化测试最初直接以 FP32 求和并断言零，出现约 `2.98e-8` 的舍入差；改为 FP64 求和，并逐位置验证 16 正、16 负。没有更改偏置或放宽真实模型的 dispatch、零偏置、重复和清理后完全一致要求。
- 8 条 init39 父轨迹均有 q8，未按成功/失败替换；源目录与 P1a/P1b 不重叠。

## 计数边界

每父状态 32 次不同候选、8 次独立参考动作、4 次规定重复、4 次独立 baseline/zero 对照，共 48 次。八状态共 384 次独立前向，另有 9 次原服务对照；预算共 393 次。

每方法每池均为四个新候选加共同默认动作。固定混合池只复用已经采集的指定候选，不额外调用模型；每次模型调用仍按实际请求记账。参考动作只定义离线距离指标，不进入候选池或生成器。

## 解释边界

本轮不使用任务成功标签，不执行模拟器动作。噪声参考分布侧重冻结策略通过改变初始噪声能产生的动作区域；它不是正确恢复动作的分布。几何覆盖较好不证明成功率更高，较差也不排除 gate 对特定局部恢复有价值。

主比较仍为状态 gate 与 IID 噪声，动作 gate 和固定混合池属于事先指定的次要对照。不能将最佳次要指标事后替换为主结果，也不能将本轮称为完成了原 P2 的物理恢复实验。

## 独立审计修正

首次独立审计在请求摘要检查处停止。逐个核对 384 个独立请求发现：所有原始输入字节摘要均与日志相同，所有重建输入数值相同；216 个 gate 请求的重建摘要仅在未干预位置的 `+0.0` / `-0.0` 上不同。

采集实现将完整正负方向乘以位置 mask，负方向在未干预位置保留 `-0.0`；独立实现以全 `+0.0` 初始化后只填写被干预位置，数值相同但字节不同。这不是噪声、方向、作用范围或模型输出的改变。

保留冻结的采集、分析及独立审计源代码，新入口 `audit_coverage_signed_zero.py` 仅在重建输入时恢复零的符号，然后执行原审计的全部检查。不改变非零 bias、指标公式或容差，不重新采集；新入口哈希及修正原因在 run 的 `audit-correction.json` 单列。

该入口随后在新增的概率重加权断言处再次停止。原断言错误地把 FP32 softmax 概率视为 logit 加法也在 FP32 中进行。相同 CUDA autocast 配置的算子预检表明，`F.linear` 及 bias 相加为 BF16，softmax 输出为 FP32；直接计算 `native_probs * exp(requested_bias)` 无法重现 BF16 舍入后的 logits。

因此新增 `diagnose_coverage_logits.py`，只重放正式实验第一个状态的 `state_gate/pool0/candidate0`，额外 VLA 调用上限 1。该调用不进入候选池或覆盖指标；单独保存在 `logit-diagnostic/`。捕获原 hook 的实际输入并复算 logits，要求原位 GPU softmax 完全一致，且动作与完整路由和原候选完全一致。

修订审计 `audit_coverage_independently_v2.py` 保留原有输入、dispatch、重复、范围、覆盖指标复算检查，恢复有符号零；不再把未考虑 logit 舍入的概率公式当成正确性条件。它改为对这次真实 logits 重放验证 bias dtype 转换、逐项加法及 softmax，并单独记录每项误差和脚本哈希。旧审计及两次失败记录保留，不改冻结采集或分析。

## 最终结果

正式 384 次独立前向 + 9 次共享对照全部完成；追加 logits 重放 1 次成功，共 394 次 VLA 前向。CPU 单元测试、原始数组审计和小型 CUDA 算子预检不属于 VLA 前向。新增环境动作 0。

最终独立审计 v2 通过，80 个候选池的所有指标重新计算一致。主方法状态 gate 的参考覆盖增益为 0.61%，IID 噪声为 17.83%；动作 gate 0.10 为 0.88%，动作 gate 等 L2 为 0.59%，固定混合池为 13.96%。gate 及混合方法均在 0/8 个父轨迹超过噪声对照。

状态、动作、等 L2 动作 gate 的平均标准化动作 RMS 分别为 0.003291、0.004871、0.003455；IID 噪声为 0.085194。三个 gate 组各 64 个不同候选均无夹爪符号变化；噪声组的 64 个候选共 61 个动作步改变了夹爪符号，不能当成 61 条独立轨迹或误伤标签。

一次真实 logits 重放确认：logits 和 bias 相加为 BF16，softmax 为 FP32；动作与完整路由和原候选完全一致。请求 +0.10 在不同位置实际成为 0.09375、0.09765625、0.099609375、0.0999755859375、0.10009765625、0.100189208984375、0.1005859375、0.1015625，最大偏离约 0.00625。真实 dtype 加法复算完全一致，CPU softmax 最大差 `2.98e-8`；原位 GPU softmax 比较完全一致。

这是已测的数值路径事实，不是“BF16 导致控制失败”的因果结论。后续若消融，可只把 bias 加法提升到 FP32，保留原始 BF16 logits 和 native 路径，在新冻结协议中检查零偏置一致性及候选覆盖；不能将更换全部 gate 计算精度和更换干预方法混在同一个对照中。本轮未执行该消融或物理续跑。
