# P2a：MoE 候选动作覆盖预检

本轮由用户在 P1b 后要求继续实验而启动。它是 P2 物理续跑前的动作空间诊断，不替代原计划的报警触发、C0 物理一致性或完整后缀实验。P1a 和 P1b 的冻结结果保持不变。

## 问题与边界

P1b 的“不稳定”指跨幅度的响应不够线性，而不是固定请求无法复现。16 次规定的非零重复完全一致；但偏置翻倍时动作响应未成比例增加，正负差分方向也变化。因此本轮不拟合线性控制器，直接测试离散候选池。

研究问题：固定状态和源噪声，晚去噪 gate 干预产生的四个候选是否有动作多样性？相对于默认动作和等候选数的 IID 噪声池，是否覆盖冻结策略本身可产生的不同动作？

- 候选由冻结 VLA 和 gate 干预产生，不训练模型，不用动作、物体真值或成功标签筛选 gate 方向。
- IID 噪声仅作为对照和独立动作参考分布，不是给 MoE 选择器增加输入。
- 离线动作距离只用于分析，不是可部署的在线选择器。
- 不执行环境动作，不计算或声称恢复率。参考动作可能本身无用，甚至不安全。

## 冻结样本

- 本地 Plus / Pro 各取基础任务 0、3、6、9，`episode_index=2, init_state_id=39`，共 8 条父轨迹。
- 固定 q8，从零计数。缺失则如实记录，不按最终结局换样本。
- 源目录与 P1a init26、P1b init47 不重叠；基础任务相同，属于开发诊断，不声称未见任务泛化。
- 准备时校验模型身份、源 trace 和任务映射，并冻结输入与实现哈希。

## 候选与公平对照

每父状态使用两个固定随机池；每池每方法四个新候选，默认动作另作为共同第五个候选保留。

| 生成器 | 干预 | 单位置偏置 RMS | 总偏置 L2 |
|---|---|---:|---:|
| noise | 4 个独立标准高斯初始噪声，无 gate bias | 0 | 0 |
| state_gate，预定主方法 | 前四 HB 层、状态 token、晚去噪 | 0.10 | 约 1.960 |
| action_gate | 前四 HB 层、10 个动作 token、晚去噪 | 0.10 | 约 6.197 |
| action_gate_l2 | 同上，总偏置 L2 与状态组匹配 | 0.10 / sqrt(10) | 约 1.960 |

每位置 32 个专家中随机 16 个正偏置、16 个负偏置，严格中心化。所有 gate 候选保持源噪声；两个动作组复用相同随机方向，只改变幅度。每池四个方向独立，不进行额外筛选；方向在父轨迹间共用以形成配对比较。与 P1b 使用不同随机流。

噪声候选按 benchmark、基础任务、init、q、pool、candidate 派生；另生成 8 个独立标准高斯参考噪声，其命名空间与两个候选池分离。参考动作不加入任何候选池。

次要报告一个固定混合池：noise 的前两个候选 + state_gate 的前两个候选 + 默认动作。该池不看结果挑候选，部署预算同为四次新前向；本轮原始采集已包含这些前向，不重复计费。

## 预算与完整性

每父状态：bare、native、zero 三次；2 x 4 x 4 = 32 次候选；8 次参考动作；四个生成器各重复 pool0/candidate0 一次；post 一次，共 48 次独立模型前向。

八状态最多 384 次独立前向；逐状态原服务对照及末尾原服务对照共 9 次，正式总预算 393 次。候选 256 次、参考动作 64 次、重复 32 次、独立 native/zero/bare/post 对照 32 次。参考动作和重复不是新的独立父轨迹。

- 复用已审计的独立模型运行器、实际 gate hook 和按实际 dtype 的精确 dispatch 核对；保留 16 GiB PyTorch 分配上限与额外显存余量。
- 不修改、切换或重启 9500，也不终止其他任务。共享对照仅发送合法请求并追加独立 ID 的记录。
- 每状态 bare/native/zero/post 与共享服务及源 trace 对齐；四个规定重复的动作和完整路由必须完全一致。
- 保存所有输入、噪声、偏置、完整 HB/AS、实际专家 ID/权重、请求响应日志、耗时、显存和 SHA-256。
- 每次请求后 hook 必须移除。异常停止，不自动覆盖、补采或隐藏失败调用。

## 预先指定分析

动作使用前六维，除以 checkpoint action std；每个动作块为 10 x 6。夹爪符号另报，不纳入距离。

1. 每池相对默认的平均/最大动作 RMS、五候选两两 RMS，以及从默认出发的四个方向的参与率维数 `(sum(s^2))^2/sum(s^4)`。该量不超过 4，不是模型的全局自由度。
2. 参考覆盖增益：对每个参考动作，计算 `1 - 候选池最近距离 / 默认动作距离`，再平均。共同保留默认，指标不小于 0；参考与默认距离为零时记缺失。使用真实幅度，不缩放候选来人为扩大覆盖。
3. 方向参考：四个候选变化与参考变化的最大正余弦。此项只观察方向，不替代实际幅度下的覆盖。
4. 主比较为 state_gate 相对 noise 的覆盖增益差；其他方法和固定混合池全部附报。先平均每父状态的两个池，再对八父轨迹等权；列出逐父状态结果、优于 noise 的父轨迹数，不把候选或参考数量当作独立样本。
5. 保存每候选实际总 bias L2、路由变化、夹爪符号变化和每池明细。状态组与 action_gate_l2 为等 L2 对照；action_gate 与状态组只有单位置幅度相同。

参考分布由 IID 噪声定义，天然侧重噪声可达到的动作区域。gate 覆盖较差不代表它在所有恢复问题中无用；较好也不代表更正确。这里不做恢复收益判定，不将几何指标替代原 P2 的“额外可救父轨迹”门槛。

本轮收集、分析、独立审计后停止，交付全部方法的结果。物理续跑与成功标签需另行冻结协议，不自动启动 P3 选择器训练。
